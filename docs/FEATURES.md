# 기능 대응표

첫 프리뷰에서 재생 엔진의 잠재적 기능과 LumaPlayer UI에 구현한 기능은 다릅니다. 아래는 팟플레이어 수준을 목표로 한 초기 대응 목록이며, 전체 기능이 완료되었다는 선언이 아닙니다.

| 영역 | 프리뷰 구현 | 남은 작업 / 검증 |
|---|---|---|
| Blu-ray 실물 | 드라이브 감지, AACS/BD+ 연동, HDMV 메뉴, 리모컨, 타이틀·챕터 | 디스크별 호환성, BD-J 실물, BD-Live/PiP/멀티앵글 |
| 보호 콘텐츠 | 로컬 libaacs/libbdplus 경로 | 모든 디스크 보장 불가; Widevine/PlayReady/상용 DRM 인증은 별도 |
| 일반 파일 | libmpv, 파일 열기, 드롭, AV1/H.264/HEVC 등 엔진 코덱 | 코덱·컨테이너별 파일 테스트 확대 |
| 재생 제어 | 일시정지, 시간 탐색, 챕터, 속도, 음량, 전체 화면 | 프레임 이동, A–B 반복, 북마크, 이어보기, 구간 편집 |
| 오디오 | 트랙 선택, 기본 출력 | 장치 선택, WASAPI 독점, 비트스트림, DSP/EQ, 지연, 채널 매핑 |
| 자막 | 내부/외부 자막, SRT 저장, 로컬 AI 원어 인식 | 스타일·위치·동기화 UI, 이중 자막, OCR, 자막 검색·편집 |
| AI | whisper.cpp 다국어 로컬 구간 인식, 취소/재시도 | 한국어 번역, 모델 다운로드 UI, GPU 선택, 노래 인식 품질 |
| HDR / Dolby Vision | mpv gpu-next 처리 경로 | HDR10/DV 프로필별 색 정확도, HDR 디스플레이 실측, 인증 DV 출력 |
| 화면 처리 | 엔진 기본 렌더링/비율 유지 | 크롭/회전/줌, 색상·톤매핑 UI, 디인터레이스, 셰이더 |
| 라이브러리 | 로컬 파일 / 연결 디스크 | 재생목록 저장·정렬·검색, 최근 항목, 라이브러리 DB |
| 네트워크 | 엔진의 직접 URL 경로 | URL 입력 UI, HLS/DASH/RTSP, 네트워크 재연결·캐시 |
| 캡처/녹화 | 미구현 | 이미지 캡처, 연속 캡처, 비보호 스트림 녹화 |
| 입력·접근성 | 키보드, 마우스, 기본 Qt 접근성 | 키 매핑, 리모컨·게임패드, 스크린리더·고대비 실측 |
| 플랫폼 | Windows x64 빌드/포터블 | Linux 네이티브 실물 테스트·패키징, Wayland; macOS는 현재 범위 밖 |
| 배포·버전 | Git, 변경 기록, 고정 의존성, 태그별 릴리스 | 서명된 설치 프로그램, 업데이트·롤백, 장기 호환성 테스트 |

## 알려진 제한

- 콘서트의 노래·반주·관객 소리는 음성인식에 불리합니다. AI 생성 결과는 원문/정답 가사와 일치한다고 보장하지 않습니다.
- Whisper의 번역 옵션은 영어 대상이므로 한국어 번역으로 표시하지 않습니다.
- VLC의 생성 자막 갱신은 외부 자막 트랙을 추가합니다. 긴 세션에서 목록이 늘어나는 점은 후속 개선 대상입니다. 파일용 mpv 엔진은 관리 중인 생성 트랙을 교체합니다.
- 인증 Dolby Vision 패스스루와 Dolby Vision 메타데이터를 사용하는 톤매핑은 서로 다른 검증 항목입니다.
- Linux 빌드 CI 통과는 Linux 광학 드라이브·오디오·Wayland·HDR 실측 완료를 뜻하지 않습니다.
