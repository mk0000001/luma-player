# Windows physical-media and fixture validation — 2026-11-05

Status: final verification in progress; no release acceptance inferred from test discovery or engine initialization.

## Environment

- Windows 11 x64; Visual Studio 2022 MSVC 14.44; Qt 6.8.3.
- Pioneer BD-ROM BDCTD03RS USB optical drive.
- Physical volume: `TUKI_NIPPON_BUDOKAN_BD`; AACS present; two HDMV titles, zero BD-J titles.
- NVIDIA GeForce RTX 4080 Laptop GPU; Intel Arc integrated GPU also present.

## Observed native application results

The embedded LumaPlayer window displayed the disc's top menu and chapter-selection menu. Activating a chapter started the concert picture. The running title reported **6,294,288 ms (1:44:54)**, **29 chapters**, H.264 and two audio-selector entries. This was LumaPlayer/libVLC playback, not an external PowerDVD window. A separate PowerDVD baseline could not play with its installed feature entitlement and is not counted as application evidence.

Initial packaging failures were reproduced and corrected: libVLC's dependent-DLL location, followed by libbluray's separate application-directory-only AACS lookup. The configured local access database remains outside the repository and release package. No disc media or menu image is published.

## Automated checks

- Core: bounded/truncated disc metadata, playlist timing, Unicode multiline SRT, malformed timing, overlapping cues, generation rejection and canceled-chunk retry.
- Media adapter: missing runtime recovery, source selection, native remote-action ABI, optional actual bundled-library initialization.
- Subtitle jobs: literal process arguments, selected audio, shifted SRT, missing model, real child-process cancellation and timeout/retry.
- UI: a focused rate control retains its arrow-key behavior; disc shortcuts do not intercept it.
- Native opt-in: physical title/menu, decoded/displayed pictures, audio decode/output counters, pause/seek/chapter, AV1 transport and real local recognition.

The default CI native opt-in test is skipped when its media environment variables are absent. A passing default suite alone therefore does not count as real-disc or AV1 rendering validation. Final physical results and figures will be appended after the explicitly enabled local run.

## Recognition fixture

The upstream public-domain JFK speech sample produced an English SRT with the expected `country` phrase using the multilingual base model. Direct whisper-cli inference reported approximately **1.08 s** total on this machine for about **10.5 s** of audio. This is one speech fixture, not a benchmark for Japanese singing or all hardware.

## Limits

BD-J, BD+, other protected discs, HDR10/Dolby Vision color/output behavior, Linux optical/display behavior, Korean translation, bitstream audio and PotPlayer feature parity remain separate gates. User listening assessment and a full uninterrupted concert-duration endurance run have not been substituted by decoder counters.
