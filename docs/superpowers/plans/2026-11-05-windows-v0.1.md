# LumaPlayer Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a reviewable native Windows prerelease and test the inserted TUKI disc, with honest capability reporting and a local automatic-subtitle path.

**Architecture:** C++20/Qt 6 UI with libVLC disc navigation and libmpv file playback. Separate disc metadata and subtitle timeline from native windows and engines; run whisper.cpp asynchronously.

**Tech Stack:** CMake 3.25+, Qt 6.8.3 on Windows, libVLC 3.0.24, current pinned libmpv, whisper.cpp.

**Spec:** `docs/superpowers/specs/2026-11-05-luma-player-design.md`

## Global Constraints

- C++20; no Python application or Python runtime.
- GPL-3.0-or-later application. Preserve upstream license notices and source provenance.
- Do not upload the commercial disc's video, audio, menu graphics, decryption keys, credentials, private paths, or generated transcripts to GitHub.
- Never advertise universal DRM, certified Dolby Vision output, PotPlayer parity or physical-disc success without evidence.

## Review Focus

- Malformed/truncated disc metadata must return an error instead of out-of-bounds access.
- Paths containing spaces and non-ASCII text must remain literal process arguments.
- Seeking/source changes during recognition must not attach stale subtitles.
- Missing engines/models must produce a usable error, not a crash or fake success.
- Video mouse/menu input and app shortcuts must not steal each other's interactions.

**Interfaces:** `DiscInfo inspectDisc(const QString&)`; `QVector<SubtitleCue> parseSrt(const QString&)`; `QString formatTime(qint64)`; generation-aware `SubtitleTimeline`.
