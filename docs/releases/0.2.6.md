# LumaPlayer 0.2.6

## 한국어

0.2.5의 후속 수정입니다. Windows 앱에서 업데이트 확인이나 다운로드가 실패하면 **공식 다운로드 열기**를 눌러 GitHub에서 설치 파일을 받을 수 있습니다.

- **Windows x64**에서 Radeon·Intel 시스템은 기본 설치본을, NVIDIA CUDA 라이브러리가 필요하면 CUDA 포함 설치본을 선택하세요. [Windows 업데이트 안내](../UPDATES.md)
- **Android 9 이상**에서 0.2.5 앱을 사용 중이면 새 APK를 설치해 업데이트하세요. 0.2.3에서 넘어오는 경우 새 앱으로 설치되며 PC와 다시 페어링해야 합니다. [Android 연결 안내](../../android/README.md)
- **Ubuntu 24.04 x64**에서 압축을 푼 뒤 `./LumaPlayer`를 실행하세요. 시스템 라이브러리 설치 명령은 0.2.5와 같습니다. [Ubuntu 설치 안내](0.2.5.md#설치-및-업데이트)

## English

This is a follow-up to 0.2.5. If the Windows app cannot check for or download an update, select **Open official downloads** to get the installer from GitHub.

- On **Windows x64**, use the standard installer for Radeon and Intel, or the CUDA installer to bundle NVIDIA CUDA libraries. [Windows update guide](../UPDATES.md)
- On **Android 9 and later**, install the APK over the 0.2.5 app. If you are moving from 0.2.3, install it as a separate app and pair with the PC again. [Android connection guide](../../android/README.md)
- On **Ubuntu 24.04 x64**, extract the archive and run `./LumaPlayer`. The system library installation command is the same as for 0.2.5. [Ubuntu installation guide](0.2.5.md#installation-and-updates)
