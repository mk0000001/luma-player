# 0.1.0-alpha.5

## 한국어

이미 포커스된 VLC 영상에서 포인터를 움직이지 않고 클릭할 때 재생바가 복원되지 않던 [alpha.4 알려진 문제](0.1.0-alpha.4.md)를 보완하는 프리뷰입니다. 최종 소스 검사와 실제 VLC의 창/전체화면 클릭 복원 네 가지를 확인했습니다. 최종 ZIP·CI·공개 상태는 Release 검증 자산을 기준으로 확인합니다.

- **캡처 알림:** VLC 마우스 스레드의 `SetCapture`/`ReleaseCapture`를 현재 프로세스의 WinEvent로 관찰합니다. `SetWinEventHook`은 `GetCurrentProcessId`와 `WINEVENT_OUTOFCONTEXT`로 `EVENT_SYSTEM_CAPTURESTART`부터 `EVENT_SYSTEM_CAPTUREEND`까지만 구독합니다. GUI 스레드 관찰자는 이벤트 번호와 창만 기록합니다.
- **재생바 복원:** 100ms 확인 시 전경 창·캡처 이벤트의 창·포인터 아래 창의 root-owner가 플레이어인지 검사합니다. 창/전체화면 모두 적용하며 비활성 창·다른 창·팝업/모달의 이벤트 번호도 소비해 늦게 재처리하지 않습니다. 74px 바와 5초 유휴 숨김은 유지합니다.
- **입력 범위:** 전역 마우스 훅이나 Raw Input 수신기를 등록하지 않습니다. 입력 없이도 시각이 바뀌던 이전 시도는 기각했고 세션 유휴 시각은 감지에 사용하지 않습니다.
- **유지 범위:** CUDA 포함판과 코어, 엔진별 GGML 분리·공유 NVIDIA DLL 배치는 바뀌지 않습니다. 기본 Turbo Q5·선택 Kotoba 일본어 ASR, 선택 Qwen3-4B/Hy-MT2-7B Q4 번역과 최소 10초·60초 선행 정책도 유지합니다.
- **기존 버전:** `v0.1.0-alpha.4`와 ZIP·체크섬을 보존합니다. alpha.4의 CUDA·디스크·CI 검증을 새 버전의 네이티브 입력 통과로 계산하지 않습니다.

## English

This preview addresses the [alpha.4 known issue](0.1.0-alpha.4.md) where stationary clicks on already-focused VLC video could fail to restore transport controls. Final-source tests and four native VLC windowed/fullscreen recovery cases passed. Release validation assets identify final ZIP, CI and publication status.

- **Capture notifications:** Observe VLC mouse-thread `SetCapture`/`ReleaseCapture` through process-scoped WinEvents. `SetWinEventHook` subscribes only to `EVENT_SYSTEM_CAPTURESTART` through `EVENT_SYSTEM_CAPTUREEND`, using `GetCurrentProcessId` and `WINEVENT_OUTOFCONTEXT`. The GUI-thread observer records only a serial/window.
- **Transport recovery:** Every 100 ms, check player root-owner identity for the foreground, capture-event and pointer windows. Apply this in windowed/fullscreen modes, consuming background, foreign-window and popup/modal serials without replay. Retain the 74px bar and five-second idle hiding.
- **Input scope:** No global mouse hook or Raw Input receiver is registered. The earlier timestamp approach was rejected after changes without user input; session-idle timestamps are not used for detection.
- **Unchanged scope:** Preserve CUDA/core flavors, isolated engine GGML/shared NVIDIA layout, default Turbo Q5/optional Kotoba Japanese ASR, optional Qwen3-4B/Hy-MT2-7B Q4 translation and the ten-second minimum/sixty-second lookahead.
- **History:** Preserve `v0.1.0-alpha.4`, its ZIP and checksum. Its CUDA/disc/CI results do not establish native-input success for this version.
