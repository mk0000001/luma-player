# LumaPlayer 0.2.14

## 한국어

- Windows 기본 설치는 포함된 Turbo 음성 인식 모델로 오프라인에서 완료합니다. 고정밀 인식·한국어 번역 모델은 설치 화면에서 선택하면 내려받습니다. 가속 장치 검색과 런타임 설치는 **설정 → AI 가속 설정**에서 시작합니다.
- **시작 시 업데이트 확인**, **시작 시 기기 검색 켜기**, **Blu-ray 자동 검색**은 사용자가 활성화할 수 있습니다. Android에서는 **PC 검색**으로 한 번 검색하거나 **PC 자동 검색**을 켤 수 있습니다. 수신 기기에서 PC를 조작하려면 PC의 내부망 재생 창에서 권한을 켜세요.
- Windows는 자막 줄마다 배경 너비를 맞춥니다. Android는 글자와 배경을 조금 줄이고 글자에 그림자를 넣어 가독성을 유지합니다.

## English

- The default Windows setup works offline with the bundled Turbo speech recognition model. Select optional downloads in Setup for higher-accuracy recognition and Korean translation. Open **Settings → AI acceleration** to check the hardware or install a runtime.
- Startup update checks, LAN discovery at startup, and automatic Blu-ray detection can be enabled separately. On Android, tap **PC 검색** to search once or turn on **PC 자동 검색**. Enable remote playback control in the PC's LAN playback dialog to control the PC from a receiver.
- Windows fits each caption line's background to its width. Android uses slightly smaller text and a lighter background with a text shadow for readability.
