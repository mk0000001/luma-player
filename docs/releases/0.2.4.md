# LumaPlayer 0.2.4

## 한국어

한 Windows 설치본에서 Radeon 영상 디코딩, AI 음성인식, 한국어 번역을 각각 시험하고 CPU 기준과 비교할 수 있습니다. **설정 → 개발자 모드 → Radeon 가속 비교**에서 프리셋을 적용한 뒤 같은 영상 구간을 재생하세요. 마지막에 **테스트 진단 JSON 저장**을 누르면 적용 시점, 실제 사용 장치, 자원 사용량과 실패 이력을 함께 확인할 수 있습니다.

- 영상은 D3D11VA 기본 경로와 복사 경로, DXVA2 파일 복사, 실험적 Vulkan Video 복사를 비교할 수 있습니다.
- 음성인식과 번역은 각 실행기가 보고한 Radeon Vulkan 장치를 따로 선택합니다. Vulkan 번역이 실패하면 같은 GPU에서 저VRAM 설정으로 재시도한 뒤 CPU 경로를 사용할 수 있습니다.
- Radeon 실물 검증 결과는 아직 없습니다. 진단 JSON과 재현 순서를 [GitHub 이슈](https://github.com/mk0000001/luma-player/issues)에 첨부해 주세요. [가속 비교 방법](https://github.com/mk0000001/luma-player/blob/v0.2.4/docs/CAPTIONS-AND-PLAYBACK.md#radeon-가속-비교)

[Android 0.2.3 APK](https://github.com/mk0000001/luma-player/releases/download/v0.2.3/LumaPlayer-Android-0.2.3.apk)는 이 Windows 버전과 함께 사용할 수 있습니다.

## English

Compare Radeon video decoding, AI speech recognition, and Korean translation with a CPU baseline in one Windows installation. Apply a profile under **Settings → Developer Mode → Radeon acceleration comparison** and replay the same interval. **Save tester diagnostics JSON** records profile transitions, observed devices, resource use, and failures.

- File decoding offers D3D11VA, D3D11VA copy-back, DXVA2 copy-back, and experimental Vulkan Video copy-back.
- Recognition and translation select Radeon Vulkan devices independently. If explicitly selected Vulkan translation fails, the same GPU is retried with a lower-VRAM configuration before CPU fallback.
- Physical Radeon hardware validation is pending. Share a reviewed diagnostic JSON and reproduction steps in a [GitHub issue](https://github.com/mk0000001/luma-player/issues). [Acceleration comparison guide](https://github.com/mk0000001/luma-player/blob/v0.2.4/docs/CAPTIONS-AND-PLAYBACK.md#comparing-radeon-acceleration)

Use the [Android 0.2.3 APK](https://github.com/mk0000001/luma-player/releases/download/v0.2.3/LumaPlayer-Android-0.2.3.apk) with this Windows release.
