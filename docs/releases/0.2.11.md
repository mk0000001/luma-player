# LumaPlayer 0.2.11

## 한국어

- Blu-ray 챕터 위치가 디스크의 영상 인덱스와 일치하면 PC가 해당 위치에서 바로 송출을 시작합니다. 인덱스를 적용할 수 없는 디스크에는 시간 기준 탐색을 사용합니다.
- Windows PC에 직결한 츠키 무도관 실물 Blu-ray와 갤럭시 탭(SM-X736N)으로 검증했습니다. 0.2.10 정식 빌드와 수정한 송출 도우미를 적용한 0.2.10을 비교했습니다. 챕터 3을 누른 뒤 첫 프레임 표시까지 약 38.8초에서 1.7초로 줄었고, 수정 빌드는 2.3초에 재생 상태로 전환했습니다. 재생은 42초 이상 이어졌습니다.
- 같은 송출 설정으로 디코딩한 첫 다섯 프레임이 챕터 3 기준 영상과 일치했습니다. 챕터 1의 첫 프레임과는 달랐습니다.
- 챕터 이동을 개선하려면 영상을 보내는 Windows PC를 업데이트하세요.

## English

- When a Blu-ray chapter matches the disc's video index, the PC starts streaming from that position. Discs that cannot use the index continue to use timestamp-based seeking.
- Tested with the physical tuki. Nippon Budokan Blu-ray in a drive connected directly to a Windows PC and with a Galaxy Tab (SM-X736N). The comparison used the stock 0.2.10 release and 0.2.10 with the updated streaming helper. Time from tapping Chapter 3 to the first presented frame dropped from about 38.8 seconds to 1.7 seconds. The patched build reported playback at 2.3 seconds and played for more than 42 seconds.
- The first five frames decoded from the same streaming configuration matched the Chapter 3 reference. The Chapter 1 opening frame differed.
- Update the Windows PC that streams the video to get faster chapter changes.
