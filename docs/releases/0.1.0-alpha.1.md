# LumaPlayer 0.1.0-alpha.1

**보관용 개발 기록:** 이 파일은 초기 로컬 후보의 기록이며 공개 배포 완료를 뜻하지 않습니다. 이후 본편의 검은 화면·20초 정지가 보고됐으므로 아래 초기 검증 수치를 최신 합격으로 사용하지 않습니다. 현재 버전과 실제 검증 범위는 [alpha.2 기록](0.1.0-alpha.2.md)을 확인하세요.

Windows x64용 C++20/Qt 6 첫 프리뷰입니다. ZIP 전체를 풀고 `LumaPlayer.exe`를 실행하세요. 로컬 AI 음성인식 모델이 포함되어 있어 별도 Python이나 클라우드 API 키가 필요하지 않습니다.

- 츠키 `TUKI_NIPPON_BUDOKAN_BD` 실물에서 메뉴 → 본편, H.264 영상·PCM 음성 출력, 29개 챕터, 일시정지·탐색·메뉴 복귀를 검증했습니다.
- AV1/Opus와 Unicode 파일 경로, D3D11VA 하드웨어 디코딩을 검증했습니다.
- 로컬 whisper.cpp 원어 자동자막과 SRT 저장을 구현했습니다. 실물 디스크의 정확한 MPLS/선택 오디오에서 자막을 생성했고, 포터블 앱의 AV1 음성 샘플에서는 자막 3개를 생성했습니다.
- 재생 종료 중 창이 멈추던 문제, 디스크 방향키와 일반 컨트롤의 충돌, 팝업 명령, 자막 취소·재시도·시간 제한·타이틀 전환을 수정했습니다.
- Windows/Linux 빌드·테스트, 고정 의존성 체크섬, 소스·기술 자료·검증 수치·로드맵을 공개합니다.

[초기 검증 기록](../testing/2026-11-05-windows.md) · [현재 기능 상태](../FEATURES.md)

보호된 디스크에는 사용 환경의 적절한 로컬 AACS 설정이 필요합니다. 키·인증서·상용 디스크 영상/음성/메뉴·생성한 상용 디스크 자막은 배포하지 않습니다. 이번 츠키 실물 통과가 모든 디스크나 DRM의 호환성을 보장하지 않습니다.

팟플레이어 전체 기능, 한국어 번역, 인증 Dolby Vision 출력, 다른 보호 디스크/BD-J, Linux 실물·Wayland/HDR 검증은 후속 작업입니다. 콘서트의 노래 인식 정확도와 장시간 연속 재생은 별도 검증 대상이며, VLC AI 자막 갱신 시 트랙 목록이 늘어나는 제한이 남아 있습니다.

## English

This is an archived record of an early local alpha.1 candidate, not proof of a completed public release. It documented initial TUKI menu/transport, AV1 and source-caption checks. A later black-screen/freeze report invalidated broader reliability assumptions. Follow the [alpha.2 record](0.1.0-alpha.2.md) for the current implementation, validation and remaining limitations. No keys, certificates, commercial disc media or transcripts are distributed.
