# 0.1.0-alpha.2

## 한국어

이 버전은 네이티브 플레이어·로컬 자막·화면 개편을 포함하는 프리뷰입니다. 아래는 2026-11-05 **소스 빌드에서 확인한 결과**이며, 배포 ZIP의 생성·추출 검사·CI·공개 완료를 대신하지 않습니다. 버전 식별자는 `0.1.0-alpha.2` / `v0.1.0-alpha.2`입니다. 실제 공개 자산의 커밋·태그·크기·SHA-256·CI와 패키지 합격 기록은 [해당 GitHub Release](https://github.com/mk0000001/luma-player/releases)의 본문과 자산 manifest를 기준으로 확인합니다.

### 주요 변경

- **Blu-ray 안정화:** 소프트웨어 디코딩과 10초 캐시를 기본으로 사용합니다. AI를 먼저 켰을 때 First Play가 자막 대기로 멈추던 오류를 고쳐 메뉴로 자연스럽게 진행합니다. 본편은 원래의 자막 버퍼를 사용하며 수동 일시정지는 유지합니다.
- **로컬 자막:** 원문·MeCab/IPADIC 한글 독음·선택 Qwen3-4B 한국어 번역을 분리 표시합니다. ASR은 NPU 인코더/CPU 디코더·선택 GPU·CPU를 구분하고, 번역은 확인된 Arc Vulkan/CPU를 기본 배포합니다.
- **자막 준비:** 백그라운드 warmup·상주 모델·최신 요청 우선, 15초 구간·최소 10초 준비·30초 이상 목표(실제 약 30~45초 선행)와 2/4/8초 제한 재시도. 실패 후 자막 없이 계속해도 AI 설정은 유지합니다.
- **화면:** 기본 다크/선택 라이트, 자체 SVG 로고·컨트롤·Noto 글꼴, 약 74px 전체화면 바와 5초 유휴 숨김·상호작용 유지. 진단은 개발자 모드에서 표시합니다.
- **영상 설정:** 파일 출력 GPU와 AI 장치를 분리합니다. SDR/HDR 상태와 파일 전용 프레임 보간의 요청 목표·필터 FPS·화면 Hz를 구분하며 HDR/미확인 메타데이터에서는 CPU 광학 흐름을 차단합니다.
- **캡처 제외:** 보호 디스크 본창과 별도 자막 창에 Windows 캡처 제외 정책을 적용·표시합니다. DRM/HDCP 인증과 구분합니다.

### 포터블 코어와 선택 모델

`LumaPlayer.exe` 옆의 런타임·글꼴·라이선스·도구를 함께 유지합니다. 코어에는 ASR 모델과 번역 실행기를 넣되 2,497,280,256바이트(약 2.50 GB/2.33 GiB)인 선택 번역 모델은 분리합니다. [모델 설치 안내](../INSTALL-TRANSLATION.md)의 `tools/install-translation.ps1`가 고정 크기·SHA-256을 검증합니다. 설치기는 작은 HTTP 검증 파일과 실제 모델 재사용, Windows PowerShell 5.1을 확인했으며 빈 환경에서의 전체 2.50 GB 신규 다운로드를 확인한 것으로 확대하지 않습니다.

기본 번역 패키지는 Vulkan/CPU이며 번역용 OpenVINO는 제외합니다. **ASR NPU 실행기는 별도로 유지합니다.** 번역 NPU의 현재 드라이버 오류와 NVIDIA OpenVINO 충돌은 CPU 대체로 기록하며 성공 가속으로 표시하지 않습니다. [번역 검증](../local-translation.md)을 참고하세요. 설치 시에는 인터넷이 필요하고 추론 중 외부 API·계정·Python은 필요하지 않습니다.

### 남은 범위와 배포 기록

실제 디스플레이는 SDR이었습니다. HDR 소스/SDR 출력 상태와 인증 Dolby Vision·HDR 패스스루·색 정확도는 구분합니다. 무손실 디코드와 WASAPI 출력은 비트 퍼펙트·독점·HD 오디오 비트스트림을 보장하지 않습니다. 광학 흐름은 24~360 fps 목표의 CPU 실험 기능이며 합성 360 fps 타임스탬프와 별개로 1080p 예시는 약 1.4 출력 fps였습니다. 실제 360 Hz·실시간 360 fps·libVLC 메뉴 보간은 완료한 기능이 아닙니다.

최종 ZIP을 새 폴더에 푼 뒤의 재생·모델 설치·종료 검사, 그 자산의 정확한 체크섬·소스 커밋·CI·불변 태그는 배포할 때 릴리스 본문/manifest에 별도 기록합니다. 아직 생성하지 않은 자산을 이 문서에서 통과 처리하지 않습니다. 공개된 태그나 바이너리는 덮어쓰지 않습니다.

팟플레이어 전체 기능·모든 보호 디스크·인증 DRM/HDCP·Linux 실물 재생을 완료하지 않았습니다. ## English

This preview includes native playback, local captions and the UI redesign. The results below are **Windows source-build observations on 2026-11-05**, not a claim that an archive, extracted-package check, CI or publication already completed. Version identifiers are `0.1.0-alpha.2` / `v0.1.0-alpha.2`. The relevant [GitHub Release](https://github.com/mk0000001/luma-player/releases) body and asset manifest own the exact commit/tag, archive size/SHA-256, CI links and release-specific package acceptance.

### Changes and verification

The disc default is software decoding with a ten-second cache. The AI-before-open regression now lets First Play reach the menu without caption holding: **3/3 passed in 22.594 seconds**, AI still enabled. Main-title caption buffering and manual-pause intent remain separate.

Captions preserve source, native MeCab/IPADIC Hangul readings and optional Qwen3-4B Korean translation independently. Resident/background ASR preparation and newest-request scheduling use 15-second chunks, a ten-second minimum and at-least-30-second lookahead target (about 30–45 seconds, not a 30-second cap), with bounded 2/4/8-second recovery. The latest actual NPU encoder/CPU decoder buffer/UI run passed **6/6** with a warm OpenVINO compiled cache: initial **2,127ms**, seek **1,780ms**, immediate-pause check **1,125ms**. **This is not cold start.** Earlier 41.819/1.787-second cold/reuse observations have different cache/test context.

Source CTest passed **13/13 in 51.57 seconds**; subtitle-worker checks passed **15/15**, packaging checks **16/16**, installer **8/8**. Native opt-in slots skip by default, so separate actual-media runs provide hardware evidence. The requested-Arc run passed **10/10**, requested-NVIDIA reopen **6/6**: AV1, PQ/BT.2020 source→gamma2.2 SDR output, HDR optical guard, 96 kHz mono FLAC/ALAC, WASAPI clocks and four reopen/seek/pause combinations. Actual output-adapter identity was not queried: `adapterIdentityVerified=false` remains explicit.

Capture platform checks passed **4/4**. Local observation showed protected-main-window capture as black; fullscreen caption affinity was verified through the native API. Dark/light themes, three caption lines, an approximately 74 px fullscreen bar and five-second inactivity behavior were observed. This is not certified DRM/HDCP or absolute capture prevention.

The latest actual AI-enabled main-title run used the mouse's ALL PLAY action and progressed naturally for **4 minutes 17 seconds**. Eight continuous samples showed advancing video/audio counters, AI enabled, no hold and no retry. Manual pause→660.037-second seek→caption preparation preserved pause, followed by manual resume and clean shutdown. The prior approximately 20-second freeze did not recur, but **five late pictures (49–216ms)** were logged; zero jitter is not claimed. Eight hardware surface errors remain a separate reproduced limit.

See the [native acceptance record](../testing/2026-11-05-native-acceptance.md) for exact samples and scope. A long invalid/truncated translation previously stopped subsequent UI work. The fix skips only that cue; synthetic HTTP service checks passed **15/15** with UI regressions. Fatal model/runtime errors remain separate. Translation accuracy and real-time completion are not guaranteed. [Intermittent frame lateness](https://github.com/mk0000001/luma-player/issues/7) remains under investigation.

### Package and scope

Keep the runtime/fonts/notices/tools beside the executable. The core separates the optional 2,497,280,256-byte model (about 2.50 GB/2.33 GiB). The [installer](../INSTALL-TRANSLATION.md) validates pinned size/SHA-256; tests covered a small HTTP fixture, reuse of the actual model and Windows PowerShell 5.1, not a fresh full 2.50 GB download. Translation defaults to verified Vulkan/CPU and omits translation OpenVINO while retaining the independent ASR NPU runtime. Translation NPU/NVIDIA OpenVINO failures are reported with CPU fallback. Inference needs no external API account/key or Python after installation.

The tested display was SDR. HDR metadata/SDR output does not certify HDR passthrough, Dolby Vision or color accuracy. Lossless decoding/WASAPI clocks do not establish bit-perfect/exclusive/HD-audio-bitstream output. Optical flow is an experimental 24–360 fps CPU target: synthetic 360 fps timestamps passed, but the 1080p example reached only about 1.4 output fps. No physical 360 Hz, real-time 360 fps or libVLC menu interpolation is claimed.

Final archive extraction/playback/installer/shutdown results, checksum, source commit, CI and immutable tag belong in the release body/manifest for that actual artifact. They are not marked passed before creation. Published tags/binaries remain immutable. Full PotPlayer parity, universal protected-disc compatibility and Linux hardware playback remain unfinished. Commercial media/transcripts, keys and certificates are not published; scope and issue links are in the Korean section.
