# LumaPlayer 0.2.8

## 한국어

- 갤탭에서 **PC 조작 → 파일 선택**을 열어 PC가 지정한 파일을 재생할 수 있습니다. Windows의 **내부망 재생 → 갤탭에서 고를 파일 지정**에서 공유할 미디어를 고르세요.
- 갤탭의 일반 재생 화면에서 PC 컨트롤러가 챕터 위에 기본으로 표시됩니다. 재생, 앞뒤 이동, 파일 선택을 바로 쓸 수 있고, 전체화면에서는 필요할 때 컨트롤러를 열 수 있습니다.
- Blu-ray 챕터를 번호로 직접 엽니다. 갤탭은 재생한 영상 일부를 메모리에 보관해 가까운 탐색에 재사용하고, 버퍼 밖으로 이동할 때 PC에 새 위치를 요청합니다.
- 파일이나 디스크의 챕터 메타데이터에 제목이 있으면 PC와 갤탭에 표시합니다.
- PC에서 불러온 외부 자막과 준비된 AI 표시 자막을 공유를 시작할 때 갤탭에 보냅니다.
- PC와 갤탭의 재생바에 버퍼를 표시합니다. Windows 설정에서 휠로 스크롤할 때 설정값이 바뀌지 않으며 개발자 모드에서 통합 진단 로그를 저장할 수 있습니다.
- 자동 AI 가속에서 Radeon의 Vulkan 장치를 선택할 수 있습니다. 자동 선택 로직을 테스트했으며, Radeon 실물에서의 추론 성능은 미측정입니다.

실물 갤럭시 탭 SM-X736N에서 PC 파일 선택·재생, 합성 영상의 챕터 이름과 자막 트랙 제공을 확인했습니다. Windows에서 USB로 직결한 츠키 무도관 Blu-ray의 ALL PLAY를 마우스로 눌러 본편을 시작했고, 갤탭에서 본편을 1분 48초 이상 연속 재생했습니다. 3번 챕터는 선택 후 약 2초 내 첫 프레임이 표시됐으며, 5초 뒤로 이동했을 때 같은 송출 프로세스에서 1초 안팎에 프레임이 표시됐습니다. 이 디스크의 곡명은 메뉴 화면에 표시되지만 재생 엔진의 챕터 목록에 이름이 없어 번호를 표시합니다. Ubuntu는 빌드와 자동 테스트를 확인했으며 이번 버전의 실물 디스크 재생은 검증하지 않았습니다.

## English

- Open **PC controls → Select file** on the Galaxy Tab to play media approved on the PC. Choose those files under **LAN playback** on Windows.
- The Galaxy Tab shows the PC controller above chapters by default, with playback, skipping, and file selection within reach. Open it on demand in fullscreen.
- Blu-ray chapters open directly by number. Android keeps recent media in memory for nearby seeks and requests a new position from the PC when seeking outside the buffer.
- The PC and Galaxy Tab display chapter names when available in the file or disc metadata.
- The PC sends loaded external subtitles and prepared AI captions when sharing starts.
- The PC and Galaxy Tab show playback buffering in their seek bars. Scrolling in Windows settings preserves the selected values, and Developer Mode exports a unified diagnostic log.
- Automatic AI acceleration can select a Radeon Vulkan device. Device selection was tested. Radeon inference performance remains unmeasured.

On a physical Galaxy Tab SM-X736N, we verified PC file selection and playback, and confirmed named chapters and subtitle-track availability with a synthetic video. On Windows, we clicked ALL PLAY on the directly connected tuki. Nippon Budokan Blu-ray and played the main feature on the Galaxy Tab for at least 1 minute 48 seconds. Chapter 3 rendered its first frame in about 2 seconds. A 5-second rewind rendered a frame in about 1 second using the same streaming process. The disc menu shows song names, but the playback engine does not expose them as chapter names, so the list shows chapter numbers. Ubuntu passed the build and automated tests; physical Blu-ray playback was not verified for this release.
