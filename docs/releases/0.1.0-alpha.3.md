# 0.1.0-alpha.3

## 한국어

긴 자막이 화면을 넘고 잘못된 번역 표식이 보이던 문제를 고쳤습니다. 재생바를 영상 위에 겹쳐 표시하며, 외부 자막과 이어보기를 추가한 Windows 프리뷰입니다. 소스·태그·패키지는 이 버전 식별자로 구분합니다. 최종 공개 ZIP의 커밋·SHA-256·CI 결과는 GitHub Release의 검증 자산과 패키지 `manifest.json`을 기준으로 확인합니다.

- **자막 표시:** 공백 없는 긴 일본어·한국어도 줄바꿈합니다. 긴 원문은 원래 시간 안에서 짧은 페이지로 나누며 원문·독음·번역을 같은 페이지에 맞춥니다. 손상된 번역 문자·모델 제어 표식·이중 이스케이프는 표시하지 않고 다음 자막을 계속 처리합니다.
- **자막 준비:** 10초 최소 음성 인식 범위를 확보한 뒤 재생하고, 재생 중에도 60초 앞까지 계속 준비합니다. 실패가 반복되어도 최소 버퍼를 자동으로 건너뛰지 않습니다. 사용자가 선택한 ‘자막 없이 계속’과 수동 일시정지는 유지합니다. 되감기에서 이미 인식한 범위를 다시 읽어 자막이 겹치지 않게 합니다.
- **인식·번역:** 코어에 Whisper large-v3-turbo Q5를 추가했습니다. 선택 Hy-MT2-7B Q4 품질 번역 모델은 약 4.62 GB이며 별도 설치합니다. 기존 Qwen3-4B 빠른 프로필도 유지합니다. 음성 인식·번역의 GPU 선택을 분리하고 선택 CUDA 런타임 설치기를 제공합니다. 전역 드라이버나 시스템 PATH는 변경하지 않습니다.
- **외부 자막:** SRT·ASS·SSA·VTT·SMI/SAMI의 텍스트를 불러오거나 영상 위에 놓을 수 있습니다. 같은 이름의 자막은 자동으로 찾습니다. UTF-8/UTF-16과 일부 CP949/Shift-JIS 파일을 지원하며, 읽지 못하면 선택 언어의 자동자막을 켭니다. 오디오 변경에도 불러온 자막은 유지하고, 이전 가져오기 결과가 새 선택을 덮지 않게 합니다. ASS의 위치·애니메이션은 일반 텍스트로 정리됩니다.
- **화면·키:** 74px 전체화면 재생바는 영상 크기를 바꾸지 않고 겹쳐 표시됩니다. 마우스를 5초간 움직이지 않으면 숨깁니다. F/Enter/F11 전체화면, 좌우 10초 탐색, 위아래 음량 5%, M 음소거를 지원합니다. 디스크 방향 선택은 Ctrl+방향키/Ctrl+Enter입니다. 입력·목록·선택 상자·슬라이더의 기본 키 동작은 유지합니다.
- **이어서 보기:** 파일 변경 여부와 디스크/본편 타이틀을 구분합니다. 타이틀 길이의 준비 상태를 확인한 뒤 복원하며 메뉴·시작 안내가 본편 기록을 덮지 않게 합니다. 왼쪽 ‘이어서 보기’로 최근 기록을 열 수 있습니다.
- **캡처:** 지원 Windows 캡처에서는 보호 디스크의 영상과 자막만 제외하고 설정·버튼·재생바는 보이게 합니다. 인증 DRM/HDCP와 구분합니다.

사용법은 [자막과 재생 안내](../CAPTIONS-AND-PLAYBACK.md), 모델과 선택 CUDA 설치는 [설치 안내](../INSTALL-TRANSLATION.md), 의미·속도의 표본 검증은 [번역 검증](../translation-quality-validation.md)을 참고하세요.

### 확인한 범위와 남은 한계

직접 작성한 번역 개발 문장 16개와 별도 문장 12개에서 새 모델의 부정·금지·의도 보존을 검토했습니다. 일부 한국어 활용 오류와 귀환 뉘앙스 손실이 남습니다. 이 표본이 콘서트·노래 전체의 인식/번역 정확도를 보장하지는 않습니다. RTX 4080 Laptop CUDA 실제 번역과 Whisper Turbo 인식을 확인했지만, Turbo용 OpenVINO NPU 인코더나 새 번역 모델의 NPU 통과는 기록하지 않습니다. 호환 인코더가 있는 기존 base 모델의 NPU 경로와 구분합니다.

2026-11-06 네이티브 화면 확인에서 74px 바·5초 숨김·영상 크기 유지, 보호 영상만 검정으로 캡처되고 설정과 재생바가 보이는 동작을 관측했습니다. 일반 자막 변환, 취소·시간 제한, 이어보기 저장, 외부 자막 유지, 단축키와 오래된 작업 제외는 별도 자동 검사로 검증합니다. 최종 소스/실물/패키지 결과는 [이번 검증 기록](../testing/2026-11-06-alpha3-acceptance.md)에 구분합니다.

광학 드라이브의 장거리 탐색 대기와 간헐적인 지연 프레임은 계속 추적합니다. 모든 디스크·팟플레이어 전체 기능·모든 HDR/Dolby Vision 출력·인증 DRM/HDCP·360fps 실시간 보간을 완료한 제품은 아닙니다. FLAC/ALAC/LPCM 디코딩 지원과 비트퍼펙트/전용 오디오 출력을 구분합니다. Linux는 CI 빌드·자동 검사 범위이며 실물 광학 드라이브 배포 검증은 후속 작업입니다.
