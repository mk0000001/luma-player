# LumaPlayer 0.2.15

## 한국어

- **전체 모델 포함 설치**는 `windows-x64-models.exe`와 같은 이름의 번호가 붙은 `.bin` 파일을 모두 같은 폴더에 받은 뒤 EXE를 실행하세요. Whisper Base와 OpenVINO 인코더, Turbo, full-v3 Q5, Hy-MT2 한국어 번역 모델을 LZMA2로 무손실 압축해 넣었습니다. 모델을 설치하는 동안 인터넷 연결이 필요하지 않습니다.
- **단일 파일 설치 및 앱 업데이트**에는 Whisper Base와 Turbo를 포함했습니다. 파일명의 `-cuda`는 이전 버전의 업데이트 기능과 호환하기 위한 접미사입니다.
- 설치 화면에서 그래픽 장치·드라이버·메모리에 맞는 항목을 미리 선택합니다. NVIDIA CUDA는 선택 시 설치 도중 별도 아카이브를 다운로드하고 SHA-256을 확인합니다. 이미 설치된 모델과 CUDA 파일이 검증되면 재사용합니다.

## English

- **Full model setup.** Save the `windows-x64-models.exe` and all its numbered `.bin` files in the same folder, then run the EXE. The installer contains losslessly compressed Whisper Base and its OpenVINO encoder, Turbo, full-v3 Q5, and the Hy-MT2 Korean translation model. Installing these models works offline.
- **Single-file setup and app updates** include Whisper Base and Turbo. The `-cuda` suffix preserves compatibility with older updaters.
- Setup preselects components based on the GPU, driver, and memory. When selected, NVIDIA CUDA is downloaded from a separate archive and verified with SHA-256. Setup reuses existing model and CUDA files when their hashes match.
