# LumaPlayer 0.2.15

## 한국어

- Windows 설치 EXE와 CUDA·AI 모델 다운로드를 분리했습니다. 설치 화면에서 GPU·드라이버·메모리를 확인해 CUDA, 인식 모델, 한국어 번역 모델을 미리 선택합니다. 필요한 항목만 고르거나 **플레이어만 · 오프라인**으로 설치할 수 있습니다.
- 설치 프로그램은 내려받은 파일의 SHA-256을 확인하고, 설치 폴더에 같은 모델이나 CUDA 라이브러리가 이미 있으면 재사용합니다.
- 설치 EXE 이름의 `-cuda`는 이전 버전의 업데이트 기능과 호환하기 위한 접미사입니다. CUDA 런타임은 설치할 때 선택하면 별도 아카이브에서 내려받습니다.

## English

- The Windows setup EXE downloads CUDA and AI weights as separate components. Setup checks the GPU, driver and memory to preselect suitable CUDA, speech recognition and Korean translation components. Change the selections or choose **Player only (offline)**.
- Setup checks SHA-256 hashes and reuses existing models or CUDA libraries when they match the pinned files.
- The `-cuda` suffix in the setup filename preserves compatibility with older updaters. Setup downloads the CUDA runtime from its separate archive when selected.
