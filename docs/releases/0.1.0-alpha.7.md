# 0.1.0-alpha.7 — 원문 인식·음성 시간·문맥 번역 / Original recognition, speech timing and context translation

## 한국어

이 버전의 번역 순서는 **음성 → 원문 인식 → 원문 텍스트와 앞뒤 문맥 → 한국어 번역**입니다. 번역 모델에 음성을 직접 전달하지 않습니다. 새 원문이 도착하기 전에 끝난 번역을 계속 쓰던 경로를 고쳐, 진행 중 응답과 미래 자막이 최신 문맥과 일치하도록 갱신합니다. 현재 읽고 있는 완료 자막은 그 구간 동안 유지합니다.

긴 가사를 글자 수에 비례해 나누는 대신 유효한 토큰의 음성 시각으로 페이지를 나눕니다. UTF-8/UTF-16·토큰·결합 문자 경계와 쉼을 검사하고 원문·독음·번역을 같은 페이지에 표시합니다. 정렬이 없거나 유효하지 않은 구간은 기존 자막 시간을 사용합니다. native CPU가 실패해도 별도의 CLI 대체 경로를 유지하며 실패한 후보의 시간 파일을 재사용하지 않습니다.

선택 **Whisper large-v3 Q5 full** 모델(1,081,140,203바이트, MIT)을 추가했습니다. 고정 크기·SHA-256을 확인하는 설치 명령은 다음과 같습니다. 설치 후 **음성 인식 모델 선택**에서 `runtime/models/ggml-large-v3-q5_0.bin`을 고르세요. 코어 ZIP에는 기존 Turbo만 포함하며 full 모델은 별도입니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\install-asr-model.ps1 -Profile accurate
```

full-v3 구조의 native 자동 모드는 beam 5와 DTW를 사용합니다. Kotoba/Turbo 자동 설정은 유지합니다. 이 모델의 NPU 가속을 새로 검증했다고 주장하지 않습니다. 이 PC에서는 full 모델이 GPU에서 실행됐습니다. [ASR 검증 기록](../asr-model-validation.md)에 모델별 실행 속도와 한계를 남깁니다.

### 확인한 범위

- Windows Qt 검사 **22/22**, native 검사 **9/9** 통과. 비균일 token 시간·손상 metadata·CPU 대체·진행 중/미래 문맥 변경을 회귀 검사했습니다. 실제 CUDA worker의 네 결과 파일을 Qt parser와 pager로 읽어 **24개 구간 중 16개 정렬 구간, 216개 token span**을 확인했습니다.
- 같은 공개 일본어 16초 음성을 모델별 네 번 반복했습니다. full auto의 첫 추론은 **3,059.315ms**, 이후 세 번의 중앙값은 **2,686.771ms**였습니다. 신뢰할 전사 원문이 없어 CER나 노래 정확도 개선으로 해석하지 않습니다.
- 공식 Qwen3-8B Q4 후보와 기존 Hy-MT2를 직접 쓴 합성 일본어 12문장으로 비교했습니다. 24요청이 HTTP 200/정상 종료했으나 후보가 부정 지시·이름을 틀려 **채택하지 않았습니다**. 보류 표본도 사용하지 않았습니다. Hy-MT2의 말투 한계와 문맥 처리 수정은 [번역 검증 기록](../translation-quality-validation.md)에서 구분합니다.
- 연결된 실물 Blu-ray에서 초기 안내·메뉴 이후 본편이 20초를 넘어 재생됐습니다. full-v3의 GPU/DTW 또는 부분 DTW 결과, 한국어 번역과 원문·독음 표시 경로를 확인했습니다. 탐색 후 준비량 0초에서는 실제 일시정지·최소 10초 대기를 확인했고, 준비 후 자동 재개했습니다. 이 검사는 새 빌드의 로컬 실행이며 최종 ZIP 검증과 구분합니다.

최종 ZIP 크기·체크섬, 독립 추출·CI·배포 이후의 확인은 해당 GitHub Release의 `validation-*.json` 자산과 본문에 기록합니다. 이전 alpha.6 태그·ZIP·체크섬을 교체하지 않습니다. 보호 디스크 키·인증서·미디어·메뉴 이미지·인식한 상용 자막은 공개하지 않습니다.

노래·강한 배경음에서 인식과 번역 오류는 남을 수 있습니다. DTW token 시점은 가사 원문을 제공하는 강제 정렬이나 수동 음절 검수와 다릅니다. 모든 곡의 어투·의미·가사 싱크가 정확해졌다는 주장은 하지 않습니다. 기존 DRM/HDCP 인증·Dolby Vision 인증 출력 등의 확인 한계도 유지합니다.

## English

Translation follows **audio → original-language recognition → original/context text → Korean**. Audio is not sent to the translation model. In-flight responses and completed future captions are refreshed when bounded original context changes; completed text currently being read remains stable for its cue.

Validated speech-token times now determine presentation page boundaries instead of character-proportional timing. UTF-8/UTF-16, token/grapheme boundaries and pauses are preserved. Missing or invalid alignment retains coarse caption timing. Native CPU failure still has an independent legacy CLI fallback, with distinct result files.

The optional pinned MIT **full Whisper large-v3 Q5** weighs 1,081,140,203 bytes. Install it with `tools/install-asr-model.ps1 -Profile accurate`, then select `runtime/models/ggml-large-v3-q5_0.bin`. The core ZIP retains bundled Turbo and excludes the full-model weights. Native auto enables beam 5/DTW only for the verified full-v3 architecture; Kotoba/Turbo auto settings remain. Full-model NPU acceleration is not newly claimed; this PC ran it on GPU.

Windows Qt **22/22** and native **9/9** tests passed. Four actual CUDA sidecars reached the Qt parser/pager: 24 segments, 16 aligned segments and 216 token spans. Repeating the same public 16-second Japanese sample four times measured full-auto first inference at 3,059.315 ms and three warm inferences at a 2,686.771 ms median. Without a trusted transcript, these establish execution and contract handling, not CER or singing accuracy.

The official Qwen3-8B Q4 candidate was rejected after negation/name errors in twelve independently written Japanese regression captions. Both models completed all 24 requests with HTTP 200/normal stops; held-out captions were left unused. Hy-MT2 wording limits remain separate from the latest-context fix. See the linked translation/ASR records.

The connected physical disc advanced through initial navigation into the feature, beyond 20 seconds. The local new build ran full-model GPU DTW/partial alignment and Korean text translation. Seeking genuinely paused at zero caption coverage, waited for the minimum ten seconds of prepared media and resumed automatically. Final archive/extraction/CI evidence is recorded separately in this release's `validation-*.json` assets and body. Earlier alpha.6 artifacts remain immutable; protected keys, certificates, media, menu images and recognized commercial transcripts are excluded.

Singing and strong background music may still cause recognition, meaning, tone and timing errors. Token DTW is not supplied-lyrics forced alignment or manual phonetic validation. Universal lyrics accuracy, DRM/HDCP certification and certified Dolby Vision output are not claimed.
