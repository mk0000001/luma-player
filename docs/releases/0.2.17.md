# LumaPlayer 0.2.17

## 한국어

- **AI 자막 → 음성 인식 모델** 목록에서 프로그램에 포함된 모델과 사용자 폴더에 있는 모델을 선택할 수 있습니다. HeartTranscriptor와 Whisper의 주요 모델은 이름으로 표시됩니다.
- **모델 폴더 변경**으로 저장 위치를 지정하고 **폴더 열기**로 파일 탐색기에서 바로 열 수 있습니다. Whisper GGML 모델 파일(.bin)을 추가하면 목록이 갱신됩니다.
- 이전에 파일 선택 창에서 고른 모델과 새로 지정한 폴더는 앱을 다시 열어도 선택할 수 있습니다. 선택한 음성 인식 모델은 실시간 자막과 재생 전 전체 자막 생성에 사용됩니다.

## English

- Choose a bundled or user-provided model from **AI captions → Speech recognition model**. HeartTranscriptor and common Whisper models appear by name.
- Set the location with **Change model folder** and view it in your file manager with **Open folder**. Adding a Whisper GGML model (.bin) refreshes the list.
- Previously selected model files and the configured model folder are available after restarting. The chosen speech recognition model is used for live captions and whole-file preparation.
