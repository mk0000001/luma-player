# LumaPlayer 0.2.18

## 한국어

- HeartTranscriptor로 생성한 일본어 자막에서 깨진 문자가 표시되어 한국어 번역이 누락되는 문제를 수정했습니다. 모델에 맞는 가창 인식 설정을 적용하고 토큰 정렬로 자막 표시 시각을 계산합니다.
- 츠키 무도관 Blu-ray용 기본 용어집에서 `桜`, `櫻`, `さくら`, `サクラ`를 ‘벚꽃’으로 적용합니다. 번역 결과에 남은 ‘사쿠라’와 일부 조사도 보정합니다. 실시간 자막과 새로 미리 생성하는 자막에 적용되며, 기기에 저장한 디스크별 용어가 우선합니다.

## English

- Fixed corrupted Japanese text generated by HeartTranscriptor that could appear in captions and cause Korean translation to be skipped. The player uses the model's singing recognition settings and token alignment to calculate cue timing.
- The default glossary for the Tuki Budokan Blu-ray translates `桜`, `櫻`, `さくら`, and `サクラ` as ‘벚꽃’ (cherry blossom). It corrects the remaining transliteration and adjusts common Korean particles. This applies to live captions and newly prepared captions. Saved disc-specific terms take precedence.
