# 0.1.0-alpha.4

## 한국어

CUDA 음성 인식·번역 실행기를 함께 담는 Windows 프리뷰입니다. 우클릭·휠 클릭 뒤 재생바가 영상 뒤에 가려지던 문제를 고치고 선택 일본어 모델을 추가했습니다. 정확한 공개 ZIP·소스 커밋·최종 실행 결과는 GitHub Release의 검증 자산 및 패키지 manifest를 기준으로 확인합니다.

- **배포 구성:** `LumaPlayer-0.1.0-alpha.4-windows-x64-cuda.zip`은 두 CUDA 12.4 실행기를 포함합니다. `-IncludeCuda`를 생략한 `windows-x64` 코어도 유지합니다. 시스템 드라이버를 변경하지 않으며 CPU/Vulkan 경로를 유지합니다.
- **런타임 배치:** 동일 NVIDIA DLL 3개만 `runtime/cuda`에서 공유하고 Whisper와 llama.cpp의 GGML DLL은 각 엔진 폴더에 둡니다. 전체 폴더와 원문 라이선스를 함께 유지합니다.
- **모델·자막:** 기본 음성 인식 모델은 Whisper large-v3-turbo Q5입니다. 번역 fast Qwen3-4B Q4 / quality Hy-MT2-7B Q4는 별도 선택 설치입니다. 추가 번역 비교에서 확실한 의미 개선이 없어 모델·프롬프트·디코딩을 유지했습니다. 최소 10초 준비와 60초 선행 인식도 유지합니다.
- **재생바:** 활성 영상 창의 입력 후 이미 보이는 바도 앞으로 올립니다. 창 크기를 바꾸지 않고 우클릭·가운데 클릭 뒤 복원하며, 74px 전체화면 오버레이·5초 숨김을 유지합니다. 네 가지 회귀 및 Windows 파일 화면의 창/전체화면 복원을 확인했습니다.
- **선택 일본어 ASR:** Kotoba-Whisper v2.0 Q5 약 538 MB의 공식 revision·크기·해시와 Apache-2.0 원문을 고정했습니다. `tools/install-asr-model.ps1 -Profile japanese` 실행 후 음성 인식 모델 선택에서 고릅니다. 다국어 기본 Turbo와 별개이며 모든 노래의 정확도 향상을 보장하지 않습니다. [ASR 비교](../asr-model-validation.md)를 참고하세요.

## English

This Windows preview bundles CUDA ASR and translation runtimes, fixes transport stacking after right/middle clicks, and adds an optional Japanese ASR model. Release validation assets and the package manifest identify the published ZIP, exact source commit and final execution results.

- **Flavors:** `LumaPlayer-0.1.0-alpha.4-windows-x64-cuda.zip` includes both CUDA 12.4 runtimes. Omitting `-IncludeCuda` preserves the `windows-x64` core. Keep CPU/Vulkan alternatives without changing system drivers.
- **Runtime layout:** Share only three identical NVIDIA DLLs in `runtime/cuda`, keeping Whisper and llama.cpp GGML DLLs in separate engine folders. Retain the complete folder and original licenses.
- **Models/captions:** Default ASR remains Whisper large-v3-turbo Q5. Optional translation profiles remain Qwen3-4B Q4 fast and Hy-MT2-7B Q4 quality. Additional comparisons did not establish a clear semantic gain, so translation weights, prompt and decoding remain. Preserve the ten-second minimum and sixty-second lookahead.
- **Transport:** Raise an already-visible bar after video activation/input without resizing. Four regression rows and native Windows windowed/fullscreen file checks confirmed restoration, retaining the 74px overlay and five-second idle hiding.
- **Japanese ASR:** Optional Kotoba-Whisper v2.0 Q5 is about 538 MB, with pinned official revision, hash and Apache-2.0 text. Run `tools/install-asr-model.ps1 -Profile japanese`, then select its file. Multilingual Turbo remains the default. Native execution is distinct from accuracy validation; see [ASR evidence](../asr-model-validation.md).

See [installation](../INSTALL-TRANSLATION.md), [source builds](../../README.md), and [translation evidence/remaining errors](../translation-quality-validation.md).
