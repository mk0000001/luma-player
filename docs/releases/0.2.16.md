# LumaPlayer 0.2.16

## 한국어

- PC에서 LumaPlayer를 처음 실행하면 내부망 기기 검색이 켜집니다. Android 앱의 PC 목록도 처음부터 자동으로 갱신됩니다.
- PC에서 6자리 코드를 확인하고 승인해 연결한 기기는 재생·탐색·음량을 조작할 수 있습니다. 이후에 바꾼 자동 검색과 조작 허용 설정은 저장됩니다.

## English

- The PC starts LAN discovery when LumaPlayer first opens. The Android app also refreshes its PC list automatically from the first launch.
- Devices approved on the PC after checking the six-digit code can control playback, seeking, and volume. Later changes to discovery and control preferences are saved.
