# LumaPlayer 0.2.12

## 한국어

- Blu-ray가 PCM으로 출력되면 플레이어에서 음량과 음소거를 조절할 수 있습니다. 실제 비트스트림 출력에는 리시버 음량이 적용됩니다.
- 재생이 끝난 영상은 재생 버튼을 눌러 처음부터 다시 볼 수 있습니다. 재생바와 챕터 목록에 현재 챕터를 표시합니다. `K` 재생, `J/L` 10초 이동, `F` 전체화면, `I` 작은 화면, `C` 자막 표시 등은 `Shift+?`에서 확인할 수 있습니다.
- 실시간 자막을 켜거나 탐색하면 원문 10초분을 최대 12초 동안 기다립니다. 영상이 움직이기 시작하면 자막 잔량이 줄어도 계속 재생합니다. 대사가 몰리면 곧 표시될 줄부터 한국어로 번역하며, 긴 자막은 문장과 음성의 멈춤을 기준으로 나눕니다.
- Android의 자막 버튼에서 PC의 진행 상태와 실시간 자막을 확인하고 기기에서 SRT·VTT·ASS·SSA를 불러올 수 있습니다. PC에 표시하던 자막은 영상을 끊지 않고 갱신합니다.
- Windows에서 개발자 모드, 영상 캡처 허용, 성능 오버레이, 상세 진단, 강제 영상 설정이 실행할 때마다 초기화됩니다. 설치 로그와 상세 진단은 요청할 때 기록합니다.

Windows 기본 설치는 Intel과 Radeon에서도 사용할 수 있고, CUDA 설치는 NVIDIA 실행 라이브러리를 포함합니다. 설치 파일의 SHA‑256은 릴리스에 첨부합니다. 시스템 보안이 설치를 막을 때는 차단된 파일과 탐지명을 확인하세요. [설치 차단 진단](../WINDOWS-INSTALLER.md)

Blu-ray는 libVLC에서 원본 프레임으로 재생합니다. 파일 재생에서는 디스플레이 동기 혼합 상태를 확인할 수 있습니다. [재생·자막·단축키 안내](../CAPTIONS-AND-PLAYBACK.md)

Windows 11과 USB 직결 Pioneer 드라이브로 츠키 무도관 실물 Blu-ray 본편의 재생 진행, PCM 음량·음소거, GPU 원문 인식과 한국어 번역을 확인했습니다. 빠른 합성 대사 검증에서는 RTX 4080 Laptop GPU가 600ms 간격의 12줄을 표시 전에 번역했습니다. VRAM 절약 설정의 CPU 번역은 같은 시험에서 10초 앞서 시작해 1줄이 제시간에 도착했습니다.

## English

- Control volume and mute in the player when Blu-ray outputs PCM. Active bitstream audio uses receiver volume.
- Press Play at the end to restart from the beginning. The transport and chapter list show the current chapter. Use shortcuts such as `K` for play, `J/L` to seek ten seconds, `F` for fullscreen, `I` for picture-in-picture, and `C` for caption visibility. Press `Shift+?` for the list.
- When live captions start or you seek, playback waits up to 12 seconds for 10 seconds of original captions. Video continues once playback starts, even when the caption buffer runs low. Korean translation handles upcoming cues first during dense dialogue. Long captions split at sentence and speech boundaries.
- Android's caption button shows live PC status and captions and imports SRT, VTT, ASS, and SSA from the device. PC captions update without restarting the video stream.
- Developer Mode, video capture allowance, the performance overlay, detailed diagnostics, and forced video settings reset at launch on Windows. Installer logs and detailed diagnostics are collected on request.

Use the standard Windows installer for Intel or Radeon. The CUDA installer includes NVIDIA runtime libraries. Installer SHA‑256 files are attached to the release. If security software blocks installation, check the blocked file and detection name. [Installation troubleshooting](../WINDOWS-INSTALLER.md)

Blu-ray playback uses original frames in libVLC. File playback reports whether display-synchronized frame blending is active. [Playback, captions, and shortcuts](../CAPTIONS-AND-PLAYBACK.md)

On Windows 11 with a directly connected Pioneer USB drive, we observed feature playback, PCM volume and mute, GPU speech recognition, and Korean translation from the physical tuki. Nippon Budokan Blu-ray. On synthetic dialogue at a 600 ms cadence, the RTX 4080 Laptop GPU translated all 12 cues before display. With a ten-second lead, CPU translation in the VRAM-saving mode delivered one cue in time in the same test.
