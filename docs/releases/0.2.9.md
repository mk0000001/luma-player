# LumaPlayer 0.2.9

## 한국어

- 갤탭에서 Blu-ray 챕터를 선택하면 해당 챕터의 시작 시간으로 이동해 송출합니다. 챕터 3을 눌렀을 때 챕터 1 영상이 재생되는 오류를 수정했습니다.
- Windows PC와 갤탭을 페어링하고 PC에서 원격 조작을 허용하면 갤탭의 **PC 플레이어 조작**에서 디스크 메인 메뉴를 볼 수 있습니다. 메뉴 아래의 방향키와 **확인**을 사용하세요. Windows에서 영상 캡처 제외가 적용된 메뉴는 미리보기에 표시되지 않습니다.
- Blu-ray 송출 중 갤탭이 연결을 끊거나 새 재생 위치를 요청하면, 기존 FFmpeg 프로세스에 정상 종료를 먼저 요청합니다. 종료 대기 시간이 지나면 기존 정리 절차를 사용합니다.

Windows와 실물 갤럭시 탭 SM-X736N에서 합성 Blu-ray 폴더를 사용해 챕터 3의 송출 위치와 메인 메뉴 표시를 확인했습니다. 챕터 1~3의 첫 프레임도 대조했습니다. Windows 미니덤프에서는 FFmpeg가 종료될 때 Windows의 I/O 취소 경로에서 충돌한 것을 확인했습니다. 관련 하위 드라이버와 실물 디스크에서의 재발 여부는 추가 확인이 필요합니다.

실물 재검증에서는 Pioneer 드라이브를 PC USB에 직결했습니다. 갤탭에서 츠키 무도관 Blu-ray 메인 메뉴를 표시하고 ALL PLAY를 선택했습니다. 이어보기로 시작한 뒤 0초로 이동했으며, 본편이 39초를 넘길 때까지 갤탭의 영상 프레임이 계속 표시됐습니다. 챕터 3을 누르면 5분 39.714초로 송출을 시작했고, 첫 프레임은 선택 후 약 35초에 표시됐습니다. 이 재생과 송출 종료 중 Windows 재부팅 및 신규 블루스크린 이벤트는 없었습니다.

## English

- Selecting a Blu-ray chapter on the Galaxy Tab now starts the stream at that chapter's timestamp. This fixes chapter 1 video playing when chapter 3 is selected.
- After pairing the Galaxy Tab with Windows and granting remote control on the PC, open **PC controls** on the tablet to see the Blu-ray main menu. Use the arrows and **Confirm** below the preview. Menus excluded from Windows capture remain hidden in the preview.
- When the tablet disconnects or requests a new Blu-ray playback position, the host asks the existing FFmpeg process to exit gracefully. The existing cleanup procedure runs if the shutdown deadline expires.

We used synthetic Blu-ray folders on Windows and a physical Galaxy Tab SM-X736N to verify chapter 3's streaming position and main-menu display. We also checked the first frame of all three chapters. The Windows minidump showed a crash in the kernel I/O cancellation path as FFmpeg exited. The underlying driver and recurrence with a physical disc remain unverified.

For the physical retest, we connected the Pioneer drive directly to the PC by USB. We opened the tuki. Nippon Budokan Blu-ray main menu on the Galaxy Tab and selected ALL PLAY. After playback resumed at the saved position, we returned to 0:00. The Galaxy Tab continued to present video frames past 39 seconds. Chapter 3 started a stream at 5:39.714, with the first frame presented about 35 seconds after selection. Windows logged no new reboot or blue-screen event during playback or stream shutdown.
