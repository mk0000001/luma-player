# 0.1.0-alpha.6 검증 기록 / Validation record

## 한국어

상태: 개발·배포 준비 중. 이 파일은 소스 구현·관측 결과·미확인 항목을 구분합니다. NPU 실제 추론 성공이나 공개 배포 완료를 미리 주장하지 않습니다.

- 고정 Kotoba Q5용 C++ FP16 인코더 변환, 원본·IR 정체성 확인, 실제 호출 수·시간 계측과 설치기의 별도 NPU 캐시 준비를 구현했습니다. [설치 안내](../INSTALL-KOTOBA-NPU.md), [연산량·성능 기록](../PERFORMANCE-KOTOBA.md).
- 앱 CTest **21/21**, 네이티브 인코더 CTest **7/7**, PowerShell7·5.1 설치 무결성 fixture 각각 **8/8** 통과. 단위 검사를 실물 NPU 통과로 세지 않습니다.
- 실제 짧은50ms WAV에서 이전 worker는 인코딩 없이 GPU 성공을 표시했고, 새 worker는 종료22와 성공 표식 없음으로 거부했습니다. 정상16초 공개 음성의 CUDA 요청 네 번은 실제 인코더 호출1회를 각각 확인했습니다.
- 연결 Blu-ray의 시작 안내는20,020ms까지 자연 진행한 뒤 약31초 내 인터랙티브 메뉴에 진입했습니다. AI 설정은 켜진 채 유지했습니다. 과거 AACS 설정 읽기 실패의 근본 원인은 미확정이며 키 파일 복원·복사나 드라이버 변경은 하지 않았습니다.
- 전체 Kotoba NPU 컴파일은 현 드라이버에서30분 내 끝나지 않아 시험을 종료했습니다. NPU 추론·캐시 재사용·NPU로10/60초 자막 버퍼 유지는 미확인입니다. GPU 대체 경로는 유지합니다.
- 독립 코드 리뷰의 준비 제한·호출 증거·설치 검증 불일치 세 건은 수정 후 재검토에서 해소됐습니다.

최종 버전의 ZIP·체크섬·독립 추출 실행·Windows/Linux CI와 실제 설치 화면 검증은 아직 완료하지 않았습니다. 이전 버전의 태그·ZIP은 변경하지 않습니다. 보호 디스크의 키·인증서·영상·음성·메뉴·인식 자막은 공개 자료에 포함하지 않습니다.

## English

Status: development and release preparation. This record separates implementation, observations and unresolved checks; it does not claim genuine NPU success or a published release.

Implemented native Kotoba FP16 export, shared source/IR identity checks, raw per-request encoder timing/counts and separate preparation in the actual app cache. App CTest passed **21/21**, native CTest **7/7**, and installer integrity fixtures **8/8** under each PowerShell7/5.1. These do not establish hardware NPU success.

Actual50ms audio reproduced false GPU acknowledgement in the previous worker; the new worker rejects it with exit22 and no success marker. Four normal16s public-audio CUDA requests each confirmed one real encode. The connected disc's First Play advanced to20,020ms and reached its interactive menu in about31s with AI enabled. The original AACS failure's root cause remains unconfirmed; no key restoration/copy or driver changes occurred.

Full Kotoba NPU compilation did not finish within30min on the current driver and the test was terminated. Actual NPU inference, cache import and NPU10/60s caption coverage remain unverified. GPU fallback remains available. Three independent-review findings were fixed and cleared on rereview.

Final ZIP/checksum, independent extraction execution, Windows/Linux CI and installed-UI checks are pending. Earlier tags and archives remain unchanged. Protected-disc keys, certificates, media, menus and recognized transcripts are excluded from public artifacts.
