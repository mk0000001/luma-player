# LumaPlayer 0.2.13

## 한국어

- Blu-ray 타이틀이 끝난 뒤 읽기 버퍼링 상태에 머물던 문제를 수정했습니다. 재생 버튼을 누르면 같은 타이틀을 처음부터 다시 시작합니다. 재생 중 읽기 버퍼링이나 디스크 메뉴 전환은 계속 처리합니다.
- 0.2.12에서 개선한 실시간 자막, 음량 조절, Android 자막 불러오기와 개발자 설정 초기화도 포함합니다. [0.2.12 릴리스 노트](https://github.com/mk0000001/luma-player/releases/tag/v0.2.12)

## English

- Fixed Blu-ray playback remaining in a buffering state after the title ends. Press Play to restart the same title from the beginning. Buffering during playback and disc menu transitions are still handled.
- Includes the live caption, volume control, Android subtitle import, and developer settings changes from 0.2.12. [0.2.12 release notes](https://github.com/mk0000001/luma-player/releases/tag/v0.2.12)
