# LumaPlayer 0.2.19

## 한국어

- Windows 단일 파일 설치본과 전체 모델 설치본에 HeartTranscriptor Q5를 압축해 넣었습니다. 기본 설치와 앱에서 시작한 업데이트 때 함께 설치됩니다. 모델 다운로드 없이 음성 인식을 사용할 수 있습니다.
- 처음 실행할 때 **AI 자막 → 음성 인식 모델**에서 **HeartTranscriptor · 가창 · Q5**가 기본으로 선택됩니다. 다른 모델을 직접 선택한 경우에는 그 설정이 우선합니다.

## English

- Both Windows installers embed a compressed copy of HeartTranscriptor Q5. Standard setup and app-initiated updates install it alongside LumaPlayer. Speech recognition works without a separate model download.
- **HeartTranscriptor · 가창 · Q5** is selected by default under **AI captions → Speech recognition model** on first launch. Existing choices made in the model picker take precedence.
