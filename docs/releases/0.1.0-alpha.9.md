# 0.1.0-alpha.9 — 준비 타이틀·이어보기 / Prepared titles and resume

## 한국어

준비한 Blu-ray 자막을 해당 본편에 연결하지 못하던 문제를 수정합니다. 실물에서 기본 준비 타이틀은 MPLS 00003(6,296,832ms), 메뉴 ALL PLAY는 00002(6,294,288ms)였습니다. alpha.8은 다른 타이틀의 자막을 올바르게 거부했지만 준비한 본편을 직접 선택하지 못했습니다. alpha.9는 메뉴 없는 실제 native 목록에서 길이가 200ms 이내로 유일하게 맞는 타이틀을 선택하고, 선택·길이 확인 전까지 일시정지합니다. native 번호와 MPLS 번호를 같은 것으로 취급하지 않습니다. 일반 Blu-ray 버튼의 메뉴·FirstPlay 경로는 유지합니다.

직접 모드의 본편 index 0을 자막·탐색·이어보기에서 지원합니다. 이어보기는 메뉴/직접 모드와 완성 프로젝트를 저장하며 기존 기록은 메뉴 모드로 읽습니다. 소스 전환 전 기록 보존, 영상 출력 복구 중 완성 원문·번역 보존, 변경된 소스의 복구 거부도 수정했습니다.

사전 생성은 가속 대체의 제어된 사유, 중지 화면의 마지막 장치와 동일 조건 가속 재시도를 표시합니다. 재시도는 완료 구간을 보존합니다. 최초 장기 GPU 거부의 원인을 확인하거나 장치 안정성 자체를 해결한 것으로 표시하지 않습니다. [사용 안내](../PREPARE-CAPTIONS.md).

### 관측한 검증

- 전체 Windows Qt 검사 **27/27, 201.26초** 통과. 선택적으로 켜는 하드웨어 검사는 아래 실제 native 실행 결과와 구분합니다.
- 실제 Windows native UI 6개 사례와 시작/종료 검사 **8/8, 32.160초** 통과: 완성 프로젝트, 탐색·챕터, 소스 전환 기록, 소스 변경 복구 거부, 영상 복구, 실물 준비 타이틀.
- 실물 준비 프로젝트의 실제 native index 0, 6,296,832ms, 원문 2,185개·번역 2,217개 연결을 확인했습니다. 영상 프레임이 표시되고 재생 시각이 진행하며 10초 앞으로 탐색한 뒤에도 live AI hold 없이 유지됐습니다. 화면·음성 전체 구간의 수동 품질 검수는 아닙니다.
- 같은 디스크의 전체 원문 생성과 후속 한국어 번역은 alpha.8 생성 경로에서 완료했습니다. 원문 2,185개, 표시 페이지 2,244개 중 한국어 2,217개, 무효 번역 건너뜀 27개입니다. 중간 취소·재개가 포함되어 전체 처리 시간을 단일 연속 성능으로 보고하지 않습니다. alpha.9는 그 완성 프로젝트를 다시 생성하지 않고 재사용합니다.
- 가속 재시도·늦은 응답 차단, 엄격한 타이틀 메타데이터 선택, 모드별 이어보기·프로젝트 검증에 자체 fixture 회귀 검사를 추가했습니다. 전체 검사와 독립 추출 ZIP의 최종 결과는 GitHub Release의 `validation-runtime.json`·`validation-package.json`에 기록합니다.

Qwen3-ASR-1.7B도 Python 없이 별도 CUDA 환경에서 실행해 비교했지만, 공개 5.08초 시험은 기존 full-v3 Q5와 모두 정규화 CER 0/25였습니다. 비공개 30초에는 정답 대본이 없어 정확도 우위를 판단하지 않았습니다. 후보는 더 많은 VRAM·시작 시간을 사용했고 native 단어 시각이 없어 기본값이나 제품 인식기를 바꾸지 않았습니다. [측정 조건·출처·한계](../research/qwen3-asr-native-evaluation.md).

CUDA 포함 ZIP은 기본 Turbo와 실행기를 포함합니다. 선택 full-v3/Kotoba·한국어 번역 가중치는 별도입니다. Qwen 후보·보호 디스크 키·인증서·음성·영상·메뉴·상용 생성 자막·개인 경로는 포함하지 않습니다. alpha.8 이하 태그·바이너리·체크섬은 교체하지 않습니다.

GitHub Windows/Linux Actions는 실행 인프라 제한 때문에 검사 단계를 시작하지 못한 상태입니다. 로컬 Windows 통과와 구분하며 Linux 새 실행을 통과로 기록하지 않습니다. 노래 인식·어투·번역·발성 종료 정렬 및 인증 DRM/HDCP·HDR/Dolby Vision·무손실 출력의 기존 한계는 유지합니다.

## English

Fixes attachment of completed Blu-ray captions to the intended feature. The observed longest prepared MPLS 00003 (6,296,832 ms) differs from menu ALL PLAY's 00002 (6,294,288 ms). Alpha.8 correctly rejects the mismatch but cannot explicitly select the prepared title. Alpha.9 uses the actual menu-free native list, requires a unique duration match within 200 ms, and holds playback until selection/duration acknowledgment. Native indexes are not MPLS numbers. Ordinary Blu-ray playback retains menus/FirstPlay.

Direct content index 0 works for captions, seeking and resume. Resume records distinguish modes and preserve a completed project, with legacy menu-mode defaults. Source switches retain the project association, video recovery retains frozen originals/translations, and changed sources fail without crashing. Preparation shows controlled accelerator fallback reasons, last-used canceled state and checkpoint-safe identical-request retry. The initiating GPU rejection remains unconfirmed.

Full Windows Qt passed **27/27 suites in 201.26 s**; opt-in hardware coverage is reported separately. Actual Windows native UI passed **8/8 including setup/cleanup in 32.160 s**, covering six scenarios. The physical prepared project attached 2,185 originals and 2,217 translations at native index 0 / 6,296,832 ms. Displayed frames, advancing playback time and a ten-second forward seek without live AI hold were observed; this is not a perceptual audit of the complete feature.

Full generation completed through the alpha.8 generation path: 2,185 original cues, 2,244 presentation pages, 2,217 Korean translations and 27 invalid translations skipped. Interrupted/resumed work is not reported as uninterrupted performance. Alpha.9 reuses that project. Added fixture regressions cover retry/stale callbacks, strict metadata selection, mode-aware resume and project validation. Final full-suite and independently extracted package results are recorded in the release's validation JSON assets.

A separate native CUDA Qwen3-ASR-1.7B comparison found no accuracy advantage on the one supplied-reference 5.08-second speech clip: both it and current full-v3 Q5 scored 0/25 normalized character errors. The private 30-second probe has no gold reference. Higher sampled VRAM/startup needs and missing native word times also prevent an immediate replacement. See the linked evidence and limits.

The CUDA ZIP includes default Turbo and runtimes; optional full/Kotoba and Korean translation weights remain separate. Qwen candidate files and protected/private media, keys, certificates, menus, transcripts and paths are excluded. Earlier tags/binaries/checksums remain immutable. GitHub Windows/Linux test steps are infrastructure-blocked, distinct from local Windows success. Linux runtime, recognition/translation/lyric timing and certified DRM/HDR/audio limitations remain.
