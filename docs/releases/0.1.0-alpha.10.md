# 0.1.0-alpha.10 — 현재 타이틀로 준비 / Prepare the playing title

## 한국어

실물 메뉴와 재생 화면을 대조한 결과, 가장 긴 MPLS 00003(1:44:56)은 코멘터리 선택판이고 **ALL PLAY는 일반 공연 MPLS 00002(1:44:54)**였습니다. alpha.9는 선택 타이틀의 정확한 재생을 수정했지만 사전 생성 창이 현재 감상하던 타이틀을 버리고 가장 긴 타이틀로 초기화했습니다. 모델 성능 문제와 이 타이틀 선택 문제를 구분합니다. 앞서 저장한 2,185개 원문·2,217개 번역 프로젝트는 코멘터리판용으로 보존하며 일반 공연 가사의 검증으로 표시하지 않습니다.

alpha.10은 재생을 정지하기 전에 현재 디스크 경로·타이틀·오디오 순서를 전달합니다. 같은 디스크, 200ms 이내의 유일한 플레이리스트, 24시간 이내 길이와 오디오 범위를 다시 확인한 경우에만 우선 선택합니다. 다른 드라이브나 모호한 정보는 적용하지 않습니다. 정보가 없으면 가장 긴 타이틀·첫 오디오를 선택하고 메뉴와 대조하도록 안내합니다. 가장 긴 타이틀을 본편이라고 단정하지 않습니다.

- 선택 회귀 7개는 수정 전 실패를 확인했습니다. 수정 후 전체 대화상자 **18/18, 5.018초**, 실제 Windows의 자체 영상 준비 프로젝트·탐색·소스 전환·복구 **5사례+시작/종료 7/7, 13.645초**가 통과했습니다.
- 전체 Windows Qt **27/27, 254.46초** 통과. 실제 실물 메뉴에서 ALL PLAY를 연 뒤 새 창의 **00002 · 1:44:54 · 첫 오디오** 우선 선택과 재생하던 타이틀 안내도 확인했습니다. 이때 생성을 시작하거나 기존 프로젝트를 바꾸지 않았습니다.
- 일반 디스크 메뉴의 마우스 ALL PLAY로 00002에 들어가 영상 진행과 실제 GPU 자동자막·50초 이상 준비를 관측했습니다. 사전 생성의 타이틀 선택 변경과 기존 감상 중 10초/60초 정책은 별개입니다.
- 이 소스 검증 시점에 일반 공연 00002의 전체 생성은 별도 프로젝트로 **진행 중**이며 완료·가사 품질 검증으로 표시하지 않습니다. 코멘터리 프로젝트를 덮어쓰거나 타이밍을 옮겨 붙이지 않습니다. 이후의 최종 생성·독립 추출 포터블 실행 결과는 GitHub Release의 `validation-runtime.json`·`validation-package.json`에 기록합니다. 생성된 상용 자막은 로컬에만 둡니다.

ASR·번역 모델, 추론·프로젝트 형식, 보호 정책은 바꾸지 않습니다. 새 Qwen3 후보를 현재 인식기로 교체하지 않은 근거는 [실측 비교](../research/qwen3-asr-native-evaluation.md)에 있습니다. 인식·해석·가사 싱크의 정확도 한계와 최초 장기 GPU 거부의 미확정 상태는 유지합니다. alpha.9 이하 태그·파일은 보존합니다.

CUDA ASR·번역 실행기와 기본 Turbo를 포함합니다. full-v3/Kotoba·번역 가중치는 선택 설치입니다. 키·인증서·보호 미디어·메뉴 이미지·상용 생성 자막·개인 경로는 배포하지 않습니다. Windows/Linux Actions의 실행 인프라 차단은 로컬 Windows 통과와 구분하며 새로운 Linux 실측·인증 출력으로 표시하지 않습니다.
