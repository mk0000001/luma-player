# LumaPlayer 0.2.0-beta.1

## 한국어

PC에 꽂은 Blu-ray를 거실이나 다른 방에서 Android로 볼 수 있도록 내부망 재생을 추가했습니다. 앱 첫 화면에서 PC를 선택하거나 사설 IP를 입력하세요. 첫 연결은 휴대폰에서 6자리 코드 일치를 확인하고 PC에서 승인합니다. 기억한 기기는 다시 연결할 때 승인 없이 사용할 수 있습니다. 로컬 동영상과 PC에서 준비한 자막도 공유할 수 있습니다. [연결 안내](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/LAN-PLAYBACK.md)

Windows x64 설치 EXE에는 CUDA 라이브러리와 기본 Turbo 인식 모델이 포함됩니다. 권장 설치에서 full-v3 Q5 인식 모델과 Hy-MT2 번역 모델을 내려받습니다. Android APK는 Android 9 이상을 대상으로 합니다. [Windows 설치 안내](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/WINDOWS-INSTALLER.md)

페어링과 재생은 선택한 사설 IPv4 서브넷에서 TLS로 연결합니다. Android의 보안 영상 표면은 캡처 시 영상 부분을 가립니다. Blu-ray는 영상 스트림을 복사하고 호환 음성은 AAC 스테레오로 보냅니다. 원본 파일 공유는 HDR·Dolby Vision·공간 음향 데이터를 그대로 전달합니다. 실제 출력은 소스, Android 디코더와 디스플레이 또는 오디오 장치에 따라 달라집니다. 실기기의 HDR·Dolby Vision·Dolby Atmos 출력은 검증 대기 중입니다.

Windows 검증 PC는 Core Ultra 9 185H, 32 GB RAM, RTX 4080 Laptop GPU 12 GB와 PIONEER BDCTD03RS를 사용합니다. 인식과 번역을 실시간으로 함께 쓰려면 이 수준을 권장합니다. 1080p 재생과 준비된 자막 기준 추정 최소는 4코어 CPU, 8 GB RAM, H.264 하드웨어 디코딩입니다. 권장 사양에 못 미치면 재생 전 전체 자막을 만들어 사용하세요. [측정 근거](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/testing/2026-11-12-beta5-performance-security.md) · [전체 자막 준비 안내](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/PREPARE-CAPTIONS.md)

Android 16 에뮬레이터에서 사설 IP 연결, 6자리 코드 일치 확인, 매번 승인, 기기 기억과 재연결을 확인했습니다. 츠키 무도관 Blu-ray의 AVC 1080p 영상과 AAC 호환 음성이 재생됐습니다. 합성 영상의 화면 캡처에서는 영상이 가려지고 조작 UI가 보였습니다. Windows Wi‑Fi의 UDP 검색 응답과 에뮬레이터의 목록 표시는 각각 검증했습니다.

Windows 테스트 묶음 27개, Go 테스트 17개, Android 단위 테스트 6개가 통과했습니다. Windows 플레이어에서 준비된 자막이 있는 디스크를 공유하고 승인된 기기에서 스트림이 열리고 세션 정보에 자막 트랙이 표시되는 것을 확인했습니다.

## English

LAN playback lets you watch a Blu-ray loaded in the PC from another room on Android. Select a PC on the home screen or enter its private IP. Confirm the matching six-digit code on Android and approve the first connection on the PC. A remembered device can connect again without an approval prompt. You can also share local video files and captions prepared on the PC. [Connection guide](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/LAN-PLAYBACK.md)

The Windows x64 installer bundles CUDA libraries and the default Turbo recognition model. Recommended setup downloads the full-v3 Q5 recognition model and Hy-MT2 translation model. The Android APK targets Android 9 and later. [Windows installation guide](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/WINDOWS-INSTALLER.md)

Pairing and playback use TLS on the selected private IPv4 subnet. Android uses a secure surface to hide the video in captures. Blu-ray playback copies the video stream and sends stereo AAC in compatibility mode. Original file sharing preserves HDR, Dolby Vision, and spatial-audio data. Output depends on the source, Android decoder, and display or audio device. HDR, Dolby Vision, and Dolby Atmos output on physical phones is pending verification.

The Windows test PC has a Core Ultra 9 185H, 32 GB of RAM, an RTX 4080 Laptop GPU with 12 GB VRAM, and a PIONEER BDCTD03RS drive. We recommend a similar configuration for live recognition and translation together. The estimated minimum for 1080p playback with prepared captions is a four-core CPU, 8 GB of RAM, and hardware H.264 decoding. On a lower-spec PC, prepare the full captions before playback. [Measurements](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/testing/2026-11-12-beta5-performance-security.md) · [Caption preparation guide](https://github.com/mk0000001/luma-player/blob/v0.2.0-beta.1/docs/PREPARE-CAPTIONS.md)

An Android 16 emulator passed private-IP pairing, six-digit code confirmation, one-time approval, remembered pairing, and reconnection. TUKI NIPPON BUDOKAN BD played in 1080p AVC with AAC compatibility audio. Capturing the synthetic video hid the video surface and kept the controls visible. The Windows Wi-Fi discovery response and the emulator’s device list were verified separately.

All 27 Windows test suites, 17 Go tests, and six Android unit tests passed. The Windows player shared the disc with prepared captions and served the stream and advertised the caption track to an authorized client.
