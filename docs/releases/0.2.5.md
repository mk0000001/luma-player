# LumaPlayer 0.2.5

## 한국어

Android에서 영상을 재생한 채 화질, HDR, 자막 싱크와 재생 속도를 확인할 수 있습니다. 설정은 세로 화면의 하단과 넓은 가로 화면의 오른쪽에 표시됩니다. Windows에서는 Blu-ray 메뉴에서 본편으로 전환할 때 첫 영상이 멈출 수 있던 디코딩 경로를 수정했습니다. 내부망 페어링과 스트리밍 응답, 설치 파일 및 업데이트 검증도 보강했습니다.

### 설치 및 업데이트

- **Windows x64**에서 설정의 **업데이트 확인**을 누르거나 릴리스에서 설치 파일을 받으세요. Radeon·Intel 시스템은 기본 설치본, NVIDIA CUDA 라이브러리를 함께 설치하려면 CUDA 포함 설치본을 선택하세요. 기존 0.1.x 또는 0.2.x Windows 설치 위에 설치할 수 있습니다. [Windows 업데이트 안내](../UPDATES.md) · [최소·권장 사양](../../README.md)
- **Android 9 이상**에서는 APK를 설치하고 PC와 다시 페어링하세요. 공개 0.2.3과 서명 키가 달라 이번 APK는 별도 앱 ID를 사용합니다. 두 버전을 함께 설치할 수 있고, 기억한 PC와 재생 설정은 새 앱에서 다시 지정합니다. [Android 연결 안내](../../android/README.md)
- **Ubuntu 24.04 x64**에서는 아래 패키지를 설치하고 Linux 아카이브를 푼 폴더에서 `./LumaPlayer`를 실행하세요. Linux 아카이브는 시스템 Qt·VLC·mpv를 사용하는 데스크톱 빌드입니다. Windows 설치본의 CUDA·AI 모델 구성은 Windows 다운로드에서 제공합니다.

```bash
sudo apt install libqt6widgets6 libqt6network6 libvlc5 vlc-plugin-base vlc-plugin-video-output libmpv2 ffmpeg fonts-noto-cjk
```

Windows PC가 실시간 자막 권장 사양에 못 미치면 **AI 자막 → 재생 전 전체 자막 만들기**를 사용하세요. [미리 생성 안내](../PREPARE-CAPTIONS.md)

## English

On Android, check quality, HDR, subtitle sync, and playback speed while the video keeps playing. Settings open along the bottom in portrait and on the right in wide landscape. On Windows, the Blu-ray menu uses a compatible video decoding path when handing off to the feature. This release also tightens LAN pairing and stream response handling, installer payload checks, and updater validation.

### Installation and updates

- **Windows x64** users can select **Check for updates** in Settings or download an installer from the release. Use the standard installer for Radeon or Intel, or choose the CUDA installer to bundle NVIDIA CUDA libraries. It can update an existing 0.1.x or 0.2.x Windows installation. [Windows update guide](../UPDATES.md) · [Minimum and recommended hardware](../../README.md)
- **Android 9 and later** users can install the APK and pair with the PC again. This APK uses a separate application ID because its signing key differs from the public 0.2.3 APK. The two versions can coexist. Set up remembered PCs and playback preferences in the new app. [Android connection guide](../../android/README.md)
- **Ubuntu 24.04 x64** users can install the following packages, extract the Linux archive, and run `./LumaPlayer` from the extracted directory. This desktop build uses the system Qt, VLC, and mpv libraries. Bundled CUDA and AI models are available through the Windows downloads.

```bash
sudo apt install libqt6widgets6 libqt6network6 libvlc5 vlc-plugin-base vlc-plugin-video-output libmpv2 ffmpeg fonts-noto-cjk
```

If your Windows PC falls below the recommendation for live captions, use **AI Captions → Prepare full captions before playback**. [Caption preparation guide](../PREPARE-CAPTIONS.md)
