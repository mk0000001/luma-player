# 설치 빌드 1 / Installer build 1

## 한국어

플레이어 소스 `3535669c816d1d4af34165f514798e5640fd325e`의 변경하지 않은 alpha.10 CUDA 배포본을 Inno Setup 6.7.4 설치형으로 제공합니다. 설치기 소스는 별도 태그 `v0.1.0-alpha.10-installer.1`로 관리합니다. 이전 릴리스·파일·태그는 교체하지 않습니다.

설치 EXE는 **1,882,552,393바이트**, SHA-256은 `8a6301c692ed9cd21d087e1955968b72e3d6407cc526c8f979e165a996d23c67`입니다. CUDA·Qt·VC 실행 DLL·미디어/AI 엔진·기본 Turbo를 포함합니다. 추가 full-v3·Hy-MT2는 고정 주소로 자동 다운로드하고 SHA-256을 검증합니다. 사용자별 설치·시작 메뉴·제거 항목, 한국어·영어, 오프라인 기본 설치를 지원합니다.

검증: 잠금 변조·기존 출력 보존 등 12개 설치 보호 검사, 기존 ASR 설치 13개·번역 설치 7개 검사 통과. 실제 Windows에서 두 모델을 설치기로 다운로드하고 설치 종료 코드 0을 확인했습니다. 초기 다운로드 실패 시 롤백도 관측했습니다. 배포 폴더의 756개 파일과 두 모델 해시는 별도로 확인합니다. 최종 제거·재설치 관측값은 릴리스 첨부 `validation-installer.json`에 기록합니다. 가사 정확도·새 Linux·인증 DRM/HDR 검증을 추가한 릴리스가 아닙니다. 시스템 장치 드라이버·전역 PATH·사용자 동의 설정은 변경하지 않습니다.

## English

An Inno Setup 6.7.4 installer wraps the unchanged alpha.10 CUDA payload from player source `3535669c816d1d4af34165f514798e5640fd325e`. Installer sources have their own immutable tag; earlier versions and assets remain intact. The EXE is 1,882,552,393 bytes with the SHA-256 above.

Includes CUDA, Qt, VC runtime DLLs, media/AI engines and Turbo. Optional full-v3/Hy-MT2 models download from immutable URLs with SHA-256 verification. Supports per-user install, Start Menu/uninstall registration, Korean/English and offline bundled-only installation.

Validation: 12 installer integrity cases, 13 existing ASR installer cases and seven translation installer cases passed. Actual Windows installation downloaded both models and exited zero; rollback on an initial failed download was also observed. All 756 payload files and both models are independently hashed. Final uninstall/reinstall observations are in the release validation JSON. This adds no new lyric-accuracy, Linux or certified DRM/HDR claim and does not change device drivers, global PATH or acknowledged consent.
