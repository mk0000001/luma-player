# LumaPlayer 0.2.3

## 한국어

PC에서 Blu-ray나 영상 파일을 재생하고, 음성 인식과 한국어 자막을 로컬에서 처리하거나 내부망으로 Android에 보낼 수 있습니다. 이번 버전에는 AMD Radeon을 위한 Vulkan 경로와 문제를 재현한 뒤 공유할 수 있는 진단 파일을 기본 Windows 빌드에 포함했습니다.

- Windows 기본 설치 파일은 GPU 제조사에 관계없이 사용할 수 있습니다. 첫 실행 또는 **설정 → AI 가속 설정**에서 권장 라이브러리를 확인하고 CUDA, Vulkan, OpenVINO를 선택 설치합니다. Windows 자동 업데이트에는 기존 호환성을 유지하는 CUDA 포함 설치 파일을 제공합니다.
- Radeon은 Windows 파일 영상의 D3D11 가속과 Vulkan 음성 인식·번역 경로를 사용합니다. 지원 여부는 GPU 모델과 드라이버에 따라 달라집니다. 이번 검증 PC에는 Radeon 장치가 없었습니다.
- **설정 → 개발자 모드**를 켜고 문제를 재현한 뒤 **테스트 진단 JSON 저장**을 선택하세요. 지원되는 장치의 시스템·플레이어 자원 사용량을 1초 간격으로 기록하며, 최근 5분의 샘플과 재생·AI 오류를 함께 저장합니다. 재현 순서와 검토한 JSON을 [GitHub 이슈](https://github.com/mk0000001/luma-player/issues)에 첨부할 수 있습니다.
- Blu-ray 드라이브가 준비되는 동안 창을 계속 사용할 수 있습니다. Windows 11, Intel Arc, RTX 4080 Laptop GPU와 PIONEER USB 광학 드라이브 환경에서 츠키 무도관 Blu-ray의 메뉴와 본편 영상·오디오 진행을 확인했습니다. 보호 디스크는 로컬 AACS 설정이 필요합니다.
- Android는 하단 탐색바, 챕터, 연속 탭 건너뛰기, 화면 회전, 홈 PiP를 지원합니다. 기본은 원본 HDR 우선이며 균형은 최대 1080p SDR입니다.
- WireGuard 등으로 사설 IP를 연결할 수 있고, 지정한 VPN 사설 대역에서 LumaPlayer PC를 찾을 수 있습니다. [VPN과 내부망 연결 안내](https://github.com/mk0000001/luma-player/blob/v0.2.3/docs/LAN-PLAYBACK.md)

실시간 인식과 번역의 권장 사양 및 측정 조건은 [README](https://github.com/mk0000001/luma-player/blob/v0.2.3/README.md)를 참고하세요. 권장 사양에 못 미치면 [재생 전 자막 생성](https://github.com/mk0000001/luma-player/blob/v0.2.3/docs/PREPARE-CAPTIONS.md)을 사용할 수 있습니다.

## English

LumaPlayer plays Blu-ray discs and media files on a PC, runs speech recognition and Korean caption translation locally, and can stream playback to Android over a local network. This release integrates a Vulkan path for AMD Radeon and a shareable diagnostic report into the standard Windows build.

- The standard Windows installer supports multiple GPU vendors. Use the first-launch prompt or **Settings → AI acceleration** to see recommendations and optionally install CUDA, Vulkan, or OpenVINO. Windows automatic updates use the CUDA-bundled installer to preserve compatibility with existing installations.
- Radeon can use Windows D3D11 acceleration for video files and Vulkan for speech recognition and translation. Availability depends on the GPU and driver. No physical Radeon card was available on the test PC.
- Enable **Settings → Developer mode**, reproduce the problem, then choose **Save tester diagnostics JSON**. It records supported system and player resource counters every second and saves the last five minutes alongside playback and AI errors. Attach the reproduction steps and the reviewed JSON to a [GitHub issue](https://github.com/mk0000001/luma-player/issues).
- The window remains responsive while the Blu-ray drive prepares a disc. Menu navigation and main-title video and audio progression were observed on the tuki. Budokan Blu-ray using Windows 11, Intel Arc, RTX 4080 Laptop GPU, and a PIONEER USB optical drive. Protected discs require local AACS configuration.
- Android includes a bottom seek bar, chapters, repeated-tap seeking, orientation changes, and Home picture-in-picture. Original quality with source HDR is the default. Balanced caps the stream at 1080p SDR.
- A routed private IPv4 address can be used over WireGuard or a similar VPN. Receivers can also discover LumaPlayer hosts in an explicitly entered private VPN subnet. [VPN and LAN setup](https://github.com/mk0000001/luma-player/blob/v0.2.3/docs/LAN-PLAYBACK.md)

See the [README](https://github.com/mk0000001/luma-player/blob/v0.2.3/README.md) for live recognition and translation requirements and how they were measured. On systems below the recommendations, [prepare captions before playback](https://github.com/mk0000001/luma-player/blob/v0.2.3/docs/PREPARE-CAPTIONS.md).
