# LumaPlayer 0.1.0-beta.1

## 한국어

디스크 메뉴, 이어보기, 일본어 원문·한글 독음·한국어 번역을 한 앱에서 사용할 수 있는 Windows 공개 베타입니다. 설치 EXE에는 CUDA 실행 라이브러리와 Turbo가 들어 있습니다. 권장 설치에서 full-v3 Q5와 Hy-MT2를 내려받습니다. [설치 안내](../WINDOWS-INSTALLER.md)

Windows Blu-ray는 GPU 영상 디코딩을 우선 사용합니다. 재생 중 영상 프레임이 8초 동안 멈추고 디코더 오류나 오디오 진행이 확인되면 한 차례 CPU 호환 디코딩으로 위치와 준비된 자막을 복구합니다. 실시간 자막은 디스크 음성을 75초 단위로 읽고, 자막 준비와 디스크 읽기 상태를 따로 표시합니다.

창 이동 이벤트에서 영상·자막·재생 바의 위치를 바로 갱신합니다. 세 창의 위치가 한 박자 늦게 갱신되던 문제를 재현한 Windows 검사 세 개를 통과했습니다.

테스트 PC는 Windows 11 Home 26300, Intel Core Ultra 9 185H, 32 GB RAM, RTX 4080 Laptop GPU 12 GB(드라이버 617.42), SOLIDIGM NVMe SSD, PIONEER BDCTD03RS입니다. 실시간 인식과 번역을 함께 쓰려면 이 수준을 권장합니다. 권장 사양에 못 미치면 **AI 자막 → 재생 전 전체 자막 만들기**로 준비한 뒤 프로젝트를 열어 감상하세요. [전체 자막 사용법](../PREPARE-CAPTIONS.md)

로컬 Windows Qt 27개 검사 통과. 츠키 무도관 Blu-ray에서 D3D11VA로 ALL PLAY 본편과 메뉴, 일시정지, 챕터 이동, 네 번의 탐색 뒤 실제 표시 프레임·오디오 출력이 진행했습니다. 전환을 포함한 검사에서 표면 할당 경고 8회가 관측됐고, 이후 정상 재생을 확인한 구간에는 같은 경고가 없었습니다. 배포 설치본 관측값은 릴리스 첨부 검증 기록에 있습니다.

## English

The public Windows beta brings disc menus, resume, Japanese captions, Hangul readings, and Korean translation into one player. The installer includes CUDA runtime libraries and Turbo. Recommended setup downloads full-v3 Q5 and Hy-MT2. [Installation guide](../WINDOWS-INSTALLER.md)

Windows Blu-ray playback prefers GPU video decoding. If displayed frames stop for eight seconds during playback while a decoder error or advancing audio is observed, the player tries software decoding once and restores the position and prepared captions. Live captions read disc audio in 75-second windows. The interface shows disc buffering and caption preparation status.

Video, captions, and transport positions update during the window move event. Three Windows tests reproduced the lag and passed with the fix.

Test system: Windows 11 Home 26300, Intel Core Ultra 9 185H, 32 GB RAM, RTX 4080 Laptop GPU with 12 GB VRAM and driver 617.42, SOLIDIGM NVMe SSD, and PIONEER BDCTD03RS. We recommend a similar system for live recognition and translation together. On a system below that recommendation, prepare and open a completed caption project before watching. [Caption preparation guide](../PREPARE-CAPTIONS.md)

All 27 local Windows Qt suites passed. TUKI NIPPON BUDOKAN BD passed D3D11VA menu, ALL PLAY, pause, chapter and four seek checks with advancing displayed frames and audio output. Eight surface-allocation warnings were logged during the run with transitions. The subsequent steady-playback sample had none. The release validation asset records the installer observations.
