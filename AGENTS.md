# 저장소 작성 규칙 / Repository conventions

GitHub에 공개하는 설명(README, PR, 이슈, 릴리스, 개발·검증 문서)은 한국어를 먼저, 영어를 그다음에 작성합니다. 기존 라이선스 원문과 코드 식별자는 유지합니다.

Write public GitHub descriptions (README, pull requests, issues, releases, development and validation documents) in Korean first, then English. Preserve upstream license texts and code identifiers.

보호된 디스크의 키·인증서·영상·음성·메뉴 이미지·인식한 상용 콘텐츠 자막은 커밋하거나 배포하지 않습니다. 실제 검증한 장치와 기능만 통과로 기록합니다.

Never commit or distribute protected-disc keys, certificates, video, audio, menu images, or recognized commercial-content subtitles. Report only observed hardware and behavior as verified.
